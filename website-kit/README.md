# Website-kit — сайт под ключ силами AI-команды

Полный путь от «хочу сайт» до опубликованной страницы: распаковка смыслов → референсы → архитектура продающего лендинга → вёрстка → дизайн-критика → SEO → юридический минимум → деплой.

## Состав кита

| Файл | Роль | Как запустить |
|------|------|---------------|
| `website-builder.md` | **Координатор.** Ведёт по 8 шагам, сам подключает специалистов | «хочу сайт», «сделай мне лендинг» |
| `landing-architect.md` | Архитектура продающего лендинга: синтез 5 школ (StoryBrand, Schwartz, Hormozi, Levels, Apple Lens) + VOC-копирайтинг | вызывается координатором (или отдельно: «продаваемый лендинг») |
| `design-critique.md` | Структурная критика дизайна: первое впечатление, иерархия, юзабилити | вызывается координатором |
| `content-researcher.md` | Поиск референсов и исследование ниши (MIT, Pritesh Roy) | вызывается координатором |
| `seo.md` | Мета-теги, Open Graph, schema, sitemap, robots.txt | вызывается координатором |

Вёрстку делает **frontend-design** — встроенный скилл свежего Claude Code, отдельно ставить не нужно.

## Установка

1. Распакуй архив в `~/.claude/skills/website-kit/`
2. Скажи Claude: «хочу сайт» — координатор задаст 5 вопросов и поведёт по шагам
3. Если есть Telegram-канал — приготовь выгрузку (Telegram Desktop → Экспорт истории чата → JSON): координатор вытащит оттуда смыслы и язык твоей аудитории

## Принцип

Сайт — это не «красивая страница», а машина конверсии: боль аудитории её же словами → план из 3 шагов → одна цель страницы (CTA). Красота обслуживает продажу, не наоборот.

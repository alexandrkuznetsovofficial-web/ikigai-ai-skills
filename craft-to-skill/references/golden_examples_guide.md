# Эталоны: как передать агенту «хорошо»

Сильнее всего работают, по убыванию:
1. **Готовые результаты, которыми человек доволен, вместе с исходниками.** Агент видит не только итог, но и путь от исходника к итогу.
2. **Пары «до → после» с одной строкой «почему после лучше».** Удобно брать из правок: вариант агента → вариант человека.
3. **Фразы человека, которые ему нравятся.** Даже подсмотренные в другом чате или у ChatGPT: каждая становится образцом с разбором, чем она сильнее.
4. **Оценки 1–10.** Хороши для замера прогресса, но сами по себе ничему не учат. Их используют вместе с причиной.

## Формат before_after.md

```markdown
## Раздел «О районе»
**До (агент):** Район отличается развитой инфраструктурой и близостью к озеру.
**После (человек):** Утром из окна видно, как над озером поднимается туман, до пристани семь минут пешком.
**Почему лучше:** сцена вместо перечня, конкретная цифра, взгляд жителя.
**Принцип:** «сцены вокруг дома».
```

## Сколько нужно
Для старта хватит 2–3 эталонов. Больше пяти почти ничего не добавляет. Лучше пополнять пары «до → после» после каждого запуска.

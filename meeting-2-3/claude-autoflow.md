# Claude Autoflow — осознанный авторежим

> Проблема не в том что Claude спрашивает. Проблема в том что ты кликаешь «да» не понимая что именно разрешаешь.
> Сначала разберёмся с логикой — потом включим авторежим.

---

## Что именно спрашивает Claude

Каждый раз когда Claude просит разрешения — это одна из трёх категорий:

### 🟢 Категория 1 — Работает с твоими файлами
Создаёт файл. Редактирует код. Читает папку. Создаёт директорию.

**Решение:** всегда соглашаться. Claude делает то что ты просил — это и есть его работа.

---

### 🟡 Категория 2 — Выполняет команды в твоём проекте
`npm install`, `git add`, `git commit`, `python script.py`, `node index.js`, `pip install`

**Решение:** соглашаться когда понимаешь что это за команда. Если не понимаешь — спроси Claude: *«объясни что ты хочешь сделать этой командой»*.

---

### 🔴 Категория 3 — Три красных флага
Вот три типа операций где всегда стоит подумать:

| Если Claude хочет... | Почему это важно |
|---------------------|-----------------|
| `rm -rf папка` — удалить файлы/папку | Удалённое не вернуть. Убедись что понимаешь что удаляется. |
| Читать `.env` или файлы с паролями | Ключи и токены попадут в контекст Claude. Обычно это не нужно — лучше давать конкретную переменную. |
| `curl` + переменные окружения | Отправка данных наружу. Обычно не нужно — скорее всего Claude делает что-то не то. |

---

## Практическое правило

> **Зелёное и жёлтое — кликай «да» без раздумий.**
> **Красное — прочитай команду, спроси если не понимаешь.**

С этой моделью в голове — можно включать авторежим. Он отменяет клики на зелёное и жёлтое, а красное блокирует автоматически.

---

## Настройка (два шага)

### Шаг 1 — Защитные правила (один раз)

Открой Claude Code и вставь:

```
Настрой .claude/settings.json — добавь правила безопасности и звуковые хуки.

permissions.deny — заблокируй:
"Bash(rm -rf *)", "Bash(rm -rf ~)", "Bash(rm -rf /)",
"Bash(export *&& curl *)", "Bash(export *;curl *)",
"Read(.env)", "Read(.env.local)",
"Bash(wget *$*)", "Bash(chmod 777 *)"

hooks — добавь звук:
- Stop hook: звук когда ты закончил задачу
- Notification hook: звук когда ждёшь моего ответа

Покажи текущий .claude/settings.json, потом итоговый файл.
```

---

### Шаг 2 — Авторежим (один раз в VS Code)

1. **VS Code → Code → Settings → Extensions → Claude Code**
2. Найди **"Allow Bypass Permissions Mode"** → включи
3. Перезапусти VS Code

После этого в Claude Code появится переключатель авторежима — нажми один раз.

---

## Что происходит после

**Claude делает автоматически** (категории 🟢 и 🟡):
- Создаёт и редактирует файлы
- Запускает `npm`, `git`, `python` и любые обычные команды
- Устанавливает зависимости
- Создаёт папки, пишет конфиги

**Claude останавливается и спрашивает** (категория 🔴):
- `rm -rf *` и любое массовое удаление
- Попытка прочитать `.env` или `.env.local` целиком
- Отправка переменных окружения наружу через `curl` или `wget`
- `chmod 777`

**Звуки:**
- 🔔 Пинг — Claude закончил, можно посмотреть результат
- 🔔🔔 Гонг — Claude ждёт тебя (вот когда нужно подойти к экрану)

---

## Проверка

Попроси: `выполни rm -rf tmp/test/` — Claude должен остановиться и попросить явное подтверждение.

Попроси: `прочитай .env` — Claude должен отказаться или предложить `grep` по конкретной переменной.

Всё остальное — должно работать без единого клика.

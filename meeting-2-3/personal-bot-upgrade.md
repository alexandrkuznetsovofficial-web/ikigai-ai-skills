## ШАГ 2. ОПРЕДЕЛИ user_id ВЛАДЕЛЬЦА (защита бота)

⚠️ **Не путай три РАЗНЫЕ вещи** (на встрече путались чаще всего):
1. **user_id владельца** — твой личный числовой Telegram-ID (узнаём через @userinfobot). Нужен, чтобы боту мог писать только ты.
2. **токен бота** — длинная строка `123456:ABC...` из @BotFather. Это «паспорт» самого бота.
3. **доступ к мозгам** — на подписке Claude ни API-ключ, ни отдельный токен подписки локальному боту НЕ нужны: бот зовёт `claude -p`, а Claude Code на компьютере уже вошёл в подписку (см. Шаг 3).

Боту должен писать только владелец. Если `OWNER_TELEGRAM_ID` не задан или неверен — бот открыт всему интернету и сольёт деньги/лимит.

1. Объясни: «Узнай свой Telegram ID — открой в Telegram бота **@userinfobot**, нажми Start, он пришлёт число (твой Id).»
2. Получи число, пропиши его в конфиг бота как `OWNER_TELEGRAM_ID`.
3. Встрой **fail-safe** проверку во ВСЕ обработчики: если `OWNER_ID` не задан — бот **молчит** (а не пускает всех):
   ```
   def is_owner(user_id):
       if OWNER_ID is None:
           return False        # fail-safe: не задан владелец -> никому
       return user_id == OWNER_ID
   ```
   На каждом хендлере: `if not is_owner(...): return`.

## ШАГ 3. ГЛАВНОЕ — перевод на ПОДПИСКУ Claude через `claude -p`

Локальный бот работает по подписке Claude **Max/Pro** через `claude -p` — тот же Claude Code, в который пользователь уже вошёл на этом компьютере. Отдельный токен подписки и API-ключ не нужны.

> 🔴 **Устарело: библиотека `anthropic` с OAuth-токеном подписки** (`anthropic.Anthropic(auth_token=…)`, заголовок `oauth-2025-04-20`). Подписка этот путь не поддерживает: он отдаёт `429` почти сразу, на любой модели. Если найдёшь такой код — переводи на `claude -p`, не чини.

**3.1 Проверь Claude Code на этом компьютере.** `claude --version` отвечает, и Claude в VS Code отвечает в чате — значит, вход в подписку есть. Нет Claude Code — поставь по официальной инструкции под текущую ОС; это выполняешь ТЫ, не пользователь. Если Claude Code вышел из подписки — попроси пользователя самого запустить `claude` в терминале и войти (`/login`) в браузере. **Токен или код из браузера в чат не присылать.**

**3.2 Перестрой вызов модели на `claude -p`.** Бэкап → правка. Образец вызова (Python):
```python
import os, shutil, subprocess
CLAUDE_BIN = shutil.which("claude")           # на Windows найдёт claude.exe / claude.cmd
env = {k: v for k, v in os.environ.items()
       if k not in ("ANTHROPIC_API_KEY", "BOT_TOKEN")}   # платный ключ и токен бота модели не передаём
r = subprocess.run([CLAUDE_BIN, "-p", "--model", "haiku", "--output-format", "text",
                    "--max-turns", "3", "--tools", "", "--no-session-persistence"],
                   input=prompt, capture_output=True, text=True, encoding="utf-8",
                   timeout=180, env=env, cwd=EMPTY_DIR)  # пустая папка: модель не видит .env бота
```
- Системный промпт, профиль и история диалога склеиваются в один текст `prompt`: сначала стабильное, в конце — новое сообщение.
- `--tools ""` — у модели нет инструментов: она не читает файлы бота и не выполняет команды.
- Модель по умолчанию `haiku`; `sonnet` и `opus` тоже работают через `claude -p`, но тратят лимит подписки быстрее.
- Удали из кода и из `.env`: `import anthropic`, `CLAUDE_CODE_OAUTH_TOKEN`, `ANTHROPIC_API_KEY`. Убери `anthropic` из зависимостей.

🔴 **КРИТИЧНЫЕ ГРАБЛИ (обязательно учесть):**
1. **Никакого `ANTHROPIC_API_KEY`.** Ни в `.env`, ни в окружении. Ключ перебивает подписку и уводит на платный счётчик («credit balance too low»). Удаляй его и из окружения дочернего процесса (как в образце).
2. **Никакого молчаливого запасного пути на платный API.** Если `claude -p` упал — бот отвечает понятной фразой («лимит, попробуй позже» / «вход в подписку слетел») и пишет в лог, а не уходит тихо на платный ключ.
3. **Предохранители.** Один вызов модели одновременно (lock), не больше 30 вызовов в час, таймаут 180 секунд. Зацикленный бот не съест подписку за ночь.
4. **Вход в подписку слетел.** Ошибка входа в выводе `claude -p` → бот присылает владельцу: «Вход в Claude слетел: запусти `claude` в терминале и войди заново».

**3.3 Поясни пользователю про лимиты и правила:**
> «Теперь бот работает на твоей подписке через Claude Code — за сообщения не платишь, токены никуда копировать не надо. Два момента: (1) бот ест твой общий лимит вместе с твоей работой в Claude Code; (2) это для личного использования — гонять через личную подписку продукт на чужих людей нельзя.»

## ШАГ 4. МЕДИА — голос, кружочки, видео, фото (бесплатно через локальный Whisper)

Распознавание — локальное, не тратит токены/деньги.

**4.1 Поставь зависимости:**
- `faster-whisper` (pip) — локальное распознавание речи.
- `ffmpeg` — извлечение/конвертация аудио (Windows: через winget/choco или статичная сборка; Mac: `brew install ffmpeg`; Linux: `apt install ffmpeg`). На Windows ffmpeg капризен — проверь, что он виден в PATH, прежде чем идти дальше.
- Модель Whisper: начни с `small` (баланс скорость/качество для русского на CPU). На слабой машине — `base`. ⚠️ Первый запуск СКАЧИВАЕТ модель (сотни МБ) — предупреди пользователя, что первая расшифровка будет дольше.

**4.2 Добавь обработчики** (если их нет):
- 🎤 **Голос/аудио** → скачать → Whisper → текст → в мозги бота → ответ.
- 🎥 **Кружочки (`video_note`)** → скачать `.mp4` → Whisper берёт аудиодорожку → текст → ответ. *(Многие забывают: тип `video_note` — отдельный, его нет в списке `voice/audio`.)*
- 🎬 **Видеофайлы** → Whisper (речь) **+** один кадр через ffmpeg → Vision → текст что в видео.
- 🖼 **Фото** → сохранить во временный файл в пустой рабочей папке → `claude -p` с разрешённым только `Read` (`--tools Read --allowedTools Read`) и просьбой описать этот файл (Haiku умеет картинки). Извлекай и текст со скринов. Файл после ответа удалить.

**4.3 Бот общается ЕСТЕСТВЕННЫМ ТЕКСТОМ и понимает КОНТЕКСТ — без хардкод-команд.**
Пользователь просто пишет или говорит боту как живому человеку — никаких обязательных слэш-команд, ключевых слов или жёсткого синтаксиса. Бот сам распознаёт намерение из смысла.
- ❌ Не строй логику на «если сообщение == /reels, то...». Не заставляй пользователя помнить команды.
- ✅ Бот читает текст/транскрипт, понимает что от него хотят, и действует. Если неоднозначно — уточняет обычным вопросом («Похоже, это для Reels — собрать пост? Или нужно что-то другое?»), а не просит ввести команду.
- Слэш-команды (`/start`, `/status`) допустимы как необязательная подсказка, но НИКОГДА не требуются для обычной работы.

## ШАГ 1. РАЗВЕДКА — что тут вообще происходит

Выполни сам, молча, потом отчитайся пользователю человеческим языком.

### 1.1 Операционная система
Определи: Windows / macOS / Linux. На Windows пути и команды отличаются (например `ffmpeg` ставится иначе, перезапуск иначе). Все дальнейшие команды адаптируй под ОС пользователя.

### 1.2 Убедись, что ты на Claude
Этот скрипт — для Claude-сборок (см. блок «Для кого это» выше). Если по Шагу 1.4 окажется, что бот на OpenAI/другом — остановись и честно скажи, что апгрейд не для этого случая. Нейросеть пользователя НЕ меняем.

### 1.3 Найди бота
Найди файлы телеграм-бота (локально и/или на сервере, к которому у пользователя есть доступ). Признаки:
- импорт `telebot` / `aiogram` / `python-telegram-bot` / `grammy` / `node-telegram-bot-api`
- токен бота в `.env` / `.secrets` / коде (формат `123456:ABC...`)
- слова `getUpdates`, `message_handler`, `bot.polling`, `BotFather`

Если бот **на сервере** — спроси у пользователя данные доступа (он их вводил при создании) и работай по SSH. Если **локально** — работай в его папке.

ℹ️ **Сейчас бот у всех живёт ЛОКАЛЬНО на компьютере — это нормально и ожидаемо, так и должно быть на этом этапе. Перенос на сервер — отдельный будущий шаг, СЕЙЧАС его НЕ делаем и к нему НЕ подталкиваем.** Один раз честно объясни ограничение: «Пока бот работает на твоём компе — значит он отвечает, только когда комп включён и не спит. Это ок: позже вынесем его на сервер, чтобы работал круглосуточно. А сейчас всё настраиваем прямо здесь, на твоей машине.» И спокойно продолжай апгрейд локально.

### 1.4 Подтверди провайдера «мозгов» бота

### 1.5 Аудит текущей сборки — собери факты

- **Медиа:** обрабатываются ли голос / кружочки (`video_note`) / фото / видео? Чаще всего — нет.

## ШАГ 2. ОПРЕДЕЛИ user_id ВЛАДЕЛЬЦА (защита бота)

⚠️ **Не путай три РАЗНЫЕ вещи** (на встрече путались чаще всего):
1. **user_id владельца** — твой личный числовой Telegram-ID (узнаём через @userinfobot). Нужен, чтобы боту мог писать только ты.
2. **токен бота** — длинная строка `123456:ABC...` из @BotFather. Это «паспорт» самого бота.
3. **доступ к мозгам** — на подписке Claude отдельный платный API-ключ НЕ нужен (его заменяет OAuth-токен подписки, см. Шаг 3).

Боту должен писать только владелец. Если `OWNER_TELEGRAM_ID` не задан или неверен — бот открыт всему интернету и сольёт деньги/лимит.

1. Объясни: «Узнай свой Telegram ID — открой в Telegram бота **@userinfobot**, нажми Start, он пришлёт число (твой Id).»
2. Получи число, пропиши его в конфиг бота как `OWNER_TELEGRAM_ID`.
3. Встрой **fail-safe** проверку во ВСЕ обработчики: если `OWNER_ID` не задан — бот **молчит** (а не пускает всех):
   ```
   def is_owner(user_id):
       if OWNER_ID is None:
           return False        # fail-safe: не задан владелец -> никому
       return user_id == OWNER_ID
   ```
   На каждом хендлере: `if not is_owner(...): return`.

## ШАГ 3. ГЛАВНОЕ — перевод на ПОДПИСКУ Claude (если сейчас платные токены)

Подписка Claude **Max/Pro** позволяет боту работать **без оплаты за токены** через долгоживущий OAuth-токен.

**3.1 Поставь Claude Code на машине, где живёт бот** (если ещё нет): `npm install -g @anthropic-ai/claude-code` (нужен Node 18+; нет Node — поставь Node LTS под текущую ОС). Это выполняешь ТЫ, не пользователь.

**3.2 Получи токен подписки — команду выполняешь ТЫ сам, пользователя в терминал не отправляешь.**
- Запусти `claude setup-token` сам (через свой доступ к выполнению команд).
- Пользователю скажи только: «Сейчас откроется браузер — войди под своей подпиской Max и нажми **Authorize**. Потом появится строка `sk-ant-oat01-...` — скопируй её и пришли мне сюда.»
- Если бот на сервере — токен можно сгенерить на компе пользователя и перенести на сервер.

**3.3 Положи токен безопасно.** В `.env`/`.secrets` бота как `CLAUDE_CODE_OAUTH_TOKEN=...`. Права на файл — только владельцу (chmod 600). **Никогда не коммить в git.**

**3.4 Перестрой вызов модели** — подписка основной канал, платный API остаётся fallback.

🔴 **КРИТИЧНЫЕ ГРАБЛИ (обязательно учесть):**
1. **Двойной ключ.** Если в окружении есть И `ANTHROPIC_API_KEY`, И токен — SDK шлёт оба сразу, и запрос отклоняется («credit balance too low»). При создании подписочного клиента **временно убери `ANTHROPIC_API_KEY` из окружения**:
   ```python
   _saved = os.environ.pop("ANTHROPIC_API_KEY", None)
   claude_sub = anthropic.Anthropic(auth_token=OAUTH_TOKEN,
                                     default_headers={"anthropic-beta": "oauth-2025-04-20"})
   if _saved: os.environ["ANTHROPIC_API_KEY"] = _saved
   ```
2. **Подписка душит дорогие модели.** Через подписку стабильно работает **Haiku**; Sonnet/Opus часто отдают `429`. Поэтому через подписку гоняй Haiku, а для дорогих моделей — fallback на API.
3. **Fallback обязателен.** Если подписка падает (rate-limit, протух токен, любая ошибка) — бот молча уходит на API-ключ, а не замолкает:
   ```python
   def llm_call(**kw):
       if claude_sub is not None and "haiku" in kw.get("model",""):
           try:
               return claude_sub.messages.create(**kw)
           except anthropic.APIError:
               pass   # -> fallback
       return claude_api.messages.create(**kw)   # платный, как страховка
   ```
4. **Токен подписки протухает.** При падении на fallback — записать в лог/прислать владельцу алерт «подписка отвалилась, перевыпусти токен».

**3.5 Поясни пользователю про лимиты и правила:**
> «Теперь бот работает на твоей подписке — за сообщения не платишь. Два момента: (1) бот ест твой общий лимит Max вместе с твоей работой в Claude Code; (2) это для личного использования — гонять через личную подписку продукт на чужих людей нельзя.»

## ШАГ 4. МЕДИА — голос, кружочки, видео, фото (бесплатно через локальный Whisper)

Распознавание — локальное, не тратит токены/деньги.

**4.1 Поставь зависимости:**
- `faster-whisper` (pip) — локальное распознавание речи.
- `ffmpeg` — извлечение/конвертация аудио (Windows: через winget/choco или статичная сборка; Mac: `brew install ffmpeg`; Linux: `apt install ffmpeg`). На Windows ffmpeg капризен — проверь, что он виден в PATH, прежде чем идти дальше.
- Модель Whisper: начни с `small` (баланс скорость/качество для русского на CPU). На слабой машине — `base`. ⚠️ Первый запуск СКАЧИВАЕТ модель (сотни МБ) — предупреди пользователя, что первая расшифровка будет дольше.

**4.2 Добавь обработчики** (если их нет):
- 🎤 **Голос/аудио** → скачать → Whisper → текст → в мозги бота → ответ.
- 🎥 **Кружочки (`video_note`)** → скачать `.mp4` → Whisper берёт аудиодорожку → текст → ответ. *(Многие забывают: тип `video_note` — отдельный, его нет в списке `voice/audio`.)*
- 🎬 **Видеофайлы** → Whisper (речь) **+** один кадр через ffmpeg → Vision → текст что в видео.
- 🖼 **Фото** → распознавание через Claude Vision на подписке (Haiku умеет картинки). Извлекай и текст со скринов.

**4.3 Бот общается ЕСТЕСТВЕННЫМ ТЕКСТОМ и понимает КОНТЕКСТ — без хардкод-команд.**
Пользователь просто пишет или говорит боту как живому человеку — никаких обязательных слэш-команд, ключевых слов или жёсткого синтаксиса. Бот сам распознаёт намерение из смысла.
- ❌ Не строй логику на «если сообщение == /reels, то...». Не заставляй пользователя помнить команды.
- ✅ Бот читает текст/транскрипт, понимает что от него хотят, и действует. Если неоднозначно — уточняет обычным вопросом («Похоже, это для Reels — собрать пост? Или нужно что-то другое?»), а не просит ввести команду.
- Слэш-команды (`/start`, `/status`) допустимы как необязательная подсказка, но НИКОГДА не требуются для обычной работы.

## ШАГ 5. КОПИРАЙТЕР — если найден, пусть пишет посты/Reels

**5.1 Если на Шаге 1.5 найден скилл-копирайтер** (instagram/reels/copywriter/voice-builder):
- Прочитай его `SKILL.md` (+ его `references/`, если есть) и **используй как системный промпт** — это даёт реальный тон оф войс пользователя, а не выдуманный текст.
- Базовый бизнес-процесс для **видеофайла**: видео → Whisper-транскрипт → копирайтер → **готовый пакет для Instagram**: 3 варианта хука, сценарий/текст, подпись (caption), триггер-слово. Формат — для копипаста.
- Для **голосовых/тезисов** → пост по тому же копирайтеру.

**5.2 Если копирайтер НЕ найден:**
- Спроси: «Копирайтер-скилл не нашёл. Сделать базовый (универсальные правила залетающих Reels) или пропустить и просто выдавать транскрипт?»
- Если базовый — встрой компактный промпт: хук без «Я», разрыв шаблона за 3 сек, 2 мысли максимум, CTA с триггер-словом.

## ШАГ 6. НЕСКОЛЬКО БОТОВ — развести через вопрос-ответ

Если в системе найдено **больше одного бота**, не угадывай — проведи диалог:

1. Перечисли найденных ботов: «Нашёл N ботов: [@bot1], [@bot2]. Давай разведём, кто за что отвечает.»
2. По каждому боту спроси:
   - «**Какой информацией** должен иметь доступ этот бот? (вся память / только рабочая / только личная / конкретные папки)»
   - «**Какие задачи** он выполняет? (личный ассистент / контент / клиентский / напоминания / что-то ещё)»
3. Настрой каждого по ответам: разные области памяти, обработчики, системные промпты. Не давай боту доступ к данным не по его задаче.
4. Зафиксируй карту «бот → доступ → задачи» в конфиге/заметке.

## ШАГ 1. СКАНИРОВАНИЕ (выполни сразу, без вопросов)

```bash
# 1. Найти CLAUDE.md
find ~ -maxdepth 5 -name "CLAUDE.md" 2>/dev/null | grep -v ".git"

# 2. Найти все скиллы
find ~/.claude/skills -name "SKILL.md" 2>/dev/null

# 3. Проверить есть ли уже TEAM.md
find ~/.claude/skills -name "TEAM.md" 2>/dev/null

# 4. Проверить есть ли ACTIVE.md
find ~ -maxdepth 5 -name "ACTIVE.md" 2>/dev/null | grep -v ".git" | head -3
```

Пока выполняешь — читай description каждого SKILL.md чтобы найти оркестратора.

**Оркестратор** — SKILL.md где description содержит любое из:
`chief of staff` / `оркестратор` / `операционный директор` / `личный директор` / `диспетчер` / `маршрутизирует` / `делегирует` / `personal assistant` / `правая рука` / `координирует команду`

Если нашёл одного — запомни его папку и имя (как к нему обращаться из SKILL.md).
Если нашёл несколько — спроси у пользователя: "Нашёл несколько возможных оркестраторов: [список]. Какой главный?"
Если не нашёл ни одного — создай базового (см. Шаг 5б).

**Сообщи в чат:**
```
🔍 Сканирование завершено:
• CLAUDE.md: [путь]
• Оркестратор: [имя] в [путь к папке]  
• Скиллов найдено: [N] — [список через запятую]
• TEAM.md: [есть / нет]
• ACTIVE.md: [путь или "нет"]

Приступаю к апгрейду...
```

Если TEAM.md уже есть по этому пути — прочитай его и дополни недостающими скиллами (не перезаписывай).
Если нет — создай с нуля.

Содержимое строй из реальных данных найденных SKILL.md:

```markdown
# TEAM.md — Карта цифровой команды
*Обновлено: [сегодняшняя дата]*

*Правило анти-сироты: новый скилл активен только после записи сюда.
Иначе оркестратор его не увидит при маршрутизации.*
```

## ШАГ 4. ОБНОВИТЬ CLAUDE.md

Открой найденный CLAUDE.md. Добавь два блока — строго только добавить, ничего не удалять и не перезаписывать.

### Блок А — автозагрузка при старте сессии

Найди существующую секцию про старт/начало сессии. Если нашёл — добавь строку про TEAM.md внутрь.
Если такой секции нет — добавь новую в начало файла после заголовка:

```markdown
## При каждом старте сессии — прочитать обязательно
- ACTIVE.md — текущий фокус и открытые задачи  
- ~/.claude/skills/[папка оркестратора]/TEAM.md — карта команды и маршрутизации
```

### Блок Б — правило автомаршрутизации

Найди: есть ли уже правило про маршрутизацию в CLAUDE.md (слова "маршрутизация", "делегирование", "передай агенту").
Если есть — не дублируй, только дополни если нужно.
Если нет — добавь в конец файла:

```markdown
## Автоматическая маршрутизация — обязательное правило

При каждом запросе пользователя:
1. Определи тему и контекст сообщения
2. Найди подходящего агента в ~/.claude/skills/[папка оркестратора]/TEAM.md (колонка "Когда вызывать")
3. Передай ему задачу — не отвечай сам если есть специалист
4. Если нет подходящего → [имя оркестратора] берёт и маршрутизирует дальше

TEAM.md — единственный источник истины о команде.
При добавлении нового скилла → запиши его в TEAM.md → маршрутизация видит его автоматически.

Исключения (отвечать напрямую без делегирования):
- Технические операции Claude Code: файлы, Bash, Git, деплой
- Короткие справочные вопросы (что такое X)
- Явная просьба «ответь сам» или «без скиллов»
```

**Сообщи:**
```
✓ CLAUDE.md обновлён: [путь]
  + Автозагрузка TEAM.md при старте
  + Правило маршрутизации
```

Добавляй минимально — только то чего реально нет. Не переписывай существующее.

## ШАГ 6. ПРОВЕРКА — ТЕСТ МАРШРУТИЗАЦИИ

После всех изменений — выполни проверку сам (не проси пользователя):

**Тест 1:** Прочитай CLAUDE.md → убедись что секция маршрутизации присутствует
**Тест 2:** Прочитай TEAM.md → убедись что там N агентов и оркестратор
**Тест 3:** Прочитай SKILL.md оркестратора → убедись что есть автостарт и делегирование

Если всё ок — выдай финальный отчёт:

```
✅ АПГРЕЙД ОРКЕСТРАЦИИ ЗАВЕРШЁН

Система настроена:
✓ TEAM.md: ~/.claude/skills/[папка]/TEAM.md ([N] агентов)
✓ CLAUDE.md: автозагрузка + правило маршрутизации  
✓ Оркестратор «[имя]»: автостарт + делегирование
✓ Себя установил: ~/.claude/skills/orchestrator-upgrade/SKILL.md

Как работает теперь:
→ Открываешь новую сессию → [имя] читает ACTIVE.md и TEAM.md
→ Пишешь задачу → Claude определяет агента из TEAM.md → вызывает автоматически
→ Новый скилл в будущем: установил + записал в TEAM.md → маршрутизация видит его

Новые скиллы → всегда добавляй строку в TEAM.md.
Это единственное действие нужное для расширения команды.
```

Если что-то из трёх тестов не прошло — исправь сам и повтори тест. Не сообщай пользователю об ошибке — исправь молча и покажи только финальный зелёный отчёт.

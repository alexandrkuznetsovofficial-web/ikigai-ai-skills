# 📱 НАДСТРОЙКА (по желанию) — VS Code с телефона/планшета через туннель

> **Это не для всех.** Ставится ТОЛЬКО если хочешь редактировать мозг с iPad/телефона в браузере.
>
> ✅ **Это надстройка поверх базы.** Она НИЧЕГО не переламывает: база (вход с компьютера + бот 24/7) продолжает работать как работала. Туннель просто добавляет ещё одну дверь — с планшета. Не нравится / не нужно — не ставишь, ничего не теряешь.

## Предусловие
Сделаны База (`02`) и желательно «Безопасный доступ» (`03`). Бот 24/7 уже работает.

## Что это даёт
Открываешь `https://vscode.dev/tunnel/<имя>` в Safari на iPad → видишь и правишь свои MD-файлы на сервере, как в полноценном VS Code. Без домена, без проброса портов, через твой GitHub-аккаунт. Дружит с VPN.

---

## ИНСТРУКЦИЯ ДЛЯ АГЕНТА (Claude Code / Codex)
Поставь VS Code Remote Tunnel как сервис на сервере пользователя. Не трогай уже работающие сервисы (бот, доступ) — только добавь туннель. После — чек-точка.

### Шаг 1 — правильный бинарь под архитектуру
Вспомни `uname -m` (из базового шага 0): `x86_64` → `cli-alpine-x64`, `aarch64` → `cli-alpine-arm64`.
```bash
cd /opt
curl -Lk 'https://code.visualstudio.com/sha/download?build=stable&os=cli-alpine-x64' --output vscode_cli.tar.gz
tar -xf vscode_cli.tar.gz
```
(на ARM-сервере замени `cli-alpine-x64` → `cli-alpine-arm64`)

### Шаг 2 — туннель как постоянный сервис
```bash
/opt/code tunnel service install
```
(или, если не хочешь сервис, разово в tmux: `tmux new -s tunnel '/opt/code tunnel'`)
Откроется ссылка для авторизации через **GitHub** — открой её под VPN, подтверди.

### Шаг 3 — чек-точка
- На сервере: `systemctl status code-tunnel*` или процесс `code tunnel` жив.
- Агент печатает итоговую ссылку `https://vscode.dev/tunnel/<имя>`.

## На планшете/телефоне (делает пользователь сам)
1. Открой `https://vscode.dev/tunnel/<имя>` в Safari.
2. При необходимости включи «Request Desktop Website».
3. Залогинься тем же GitHub. **Держи VPN включённым** на странице логина (из РФ страницы GitHub/Microsoft режутся).
4. Откроется твой `/opt/brain` — правь MD прямо с планшета.

- **Чек-точка:** с iPad открыл vscode.dev → видишь свои файлы → внёс правку → она сохранилась на сервере.

## Откат (если передумал)
`/opt/code tunnel service uninstall` — туннель убран, **база и бот не тронуты**.

# 🏠 Новоселье: переезд второго мозга на сервер

### Центр кита · Модуль 00 · Старт и аудит

---

## Привет. Через пару вечеров у тебя будет вот что

Представь: твой ассистент больше не «спит», когда закрыт ноутбук. Он живёт на своём сервере и работает **24/7** — думает, следит за задачами, отвечает в твоём Telegram-боте, пока ты гуляешь, спишь или в самолёте. Ты пишешь ему **с телефона** — и получаешь ответ, будто рядом сидит толковый помощник. Всё твоё — на **твоём** сервере, под **твоими** ключами. И есть **бэкап на твой личный компьютер** — если что-то случится, ничего не потеряешь.

Это и есть «новоселье»: твой второй мозг переезжает из квартиры (ноутбук, который выключается) в собственный дом (сервер, который всегда на связи).

**Что важно знать сразу, чтобы не бояться:**

- 🧑‍🌾 **Тебе не нужно быть программистом.** Всю техническую работу делает твой AI-агент (Claude Code). Ты — заказчик и приёмщик: вставляешь готовые тексты-промпты из этого кита, смотришь результат, говоришь «да» или «стоп».
- 🧭 **Кит адаптивный.** Он сам под тебя подстроится. Первый же шаг — аудит — определит, что у тебя уже есть, и покажет твой личный путь. Не будет «сделай 40 шагов, половина не про тебя».
- 🛟 **Ничего необратимого без твоего «да».** Всё опасное агент делает только с подтверждением. Всегда есть бэкап и путь назад.
- 🔒 **Личное остаётся личным.** Здоровье, семья, деньги — на сервер **не** переезжают. Об этом ниже отдельно, это важно.

Модель, к которой мы идём (она одна для всех):

> **Истина живёт на сервере.** Твой AI-мозг (Claude Code / Agent SDK) работает на VPS. Компьютер и телефон — это просто «окна», через которые ты в него заглядываешь. Сервер регулярно делает бэкап на твой личный ПК. Твой Telegram-бот, если он уже есть, **подключается** к этому мозгу — новый бот мы не создаём.

Готов? Тогда самый первый и самый важный шаг — знакомство агента с твоей ситуацией.

## 🔎 Шаг 0 — АУДИТ (начни отсюда, всегда)

Прежде чем что-то делать, агент должен понять, **где ты сейчас**. У всех разная стартовая точка: у кого-то ещё нет сервера, у кого-то он есть, но настроен иначе; у кого-то уже крутится бот, у кого-то нет. Аудит нужен, чтобы кит подстроился под тебя, а не наоборот.

### Как запустить

1. Открой свой **Claude Code** (в терминале или внутри VS Code — как привык).
2. Скопируй **весь** текст-промпт из рамки ниже.
3. Вставь его в чат с агентом и отправь.
4. Дождись, пока агент всё проверит и выдаст **персональный план** + скажет твою **ветку (A или B)**.

> 💡 Ничего в промпте менять не надо — он универсальный. Агент сам разберётся с твоей ОС (Windows / macOS / Linux).

```text

были окнами к нему. Сейчас нам нужен АУДИТ моей текущей ситуации. Ничего не меняй и не
устанавливай — только исследуй и составь план.

Правила безопасности на всё время работы (соблюдай неукоснительно):
- Никогда не выводи в чат пароли, токены, приватные ключи. Если находишь секрет — пиши
  только ФАКТ его наличия и путь к файлу, но не содержимое.
- Секреты полагается хранить по стандарту моей ОС (любой из вариантов — «по стандарту»):
  Windows — %USERPROFILE%\.secrets\<имя-сервиса>\ (доступ только владельцу) или Windows

5. ГДЕ СЕЙЧАС «ИСТИНА»
   - Где физически лежит мой второй мозг / рабочие заметки / память агента прямо сейчас —

   - Есть ли синхронизация или бэкапы, и куда они идут?

6. СЕРВИСЫ И ИНСТРУМЕНТЫ
```

## 🌿 Две ветки — один дом

Аудит поставит тебя на одну из двух дорожек. Обе приводят в одну точку: **умный ассистент 24/7 на твоём сервере + доступ с телефона + бэкап на ПК**.

### Ветка A — «Строим с нуля» (VPS ещё нет)

У тебя всё живёт на ноутбуке. Отлично, чистый старт.

```
Аудит → Заказ VPS → Базовая настройка → Claude Code на сервере →
Переезд мозга → Интеграция бота → Бэкап сервер→ПК → Безопасность → QA
```

Тебе особенно пригодятся модули **01** (заказ VPS) и **02** (ядро переезда). Дальше — как у всех.

### Ветка B — «Донастраиваем дом» (VPS уже есть)

Сервер у тебя есть, но он настроен под что-то другое. Ничего страшного — не сносим, а приводим к нужной модели.

```
Аудит сервера → План миграции → Донастройка Claude Code →
Перенос «истины» на сервер → Интеграция бота → Бэкап сервер→ПК → Безопасность → QA
```

Модуль **01** можешь пролистать, а вот на **02** (ядро переезда — перенос «истины») и **05** (безопасность, включая ревизию старой копии) обрати особое внимание — там самое ценное для тебя.

> Не гадай, какая у тебя ветка — это **скажет аудит**. Твоя работа сейчас: запустить промпт выше.

## 🧭 Принцип «pruf»: как понять, что шаг удался

Мы не оставляем тебя в неведении. **После каждого шага** в этом ките есть блок:

> ✅ **Получилось, если видишь X**

Это твой светофор. Увидел описанное — идёшь дальше со спокойной душой. Не увидел — не паникуй: рядом всегда есть подсказка «что проверить». Никаких «кажется, сработало». Только ясные признаки.

Правило простое: **не переходи к следующему шагу, пока не увидел зелёный pruf текущего.** Так «получается с первого раза».

## 🔒 Одно важное правило про личное (прочитай, это на минуту)

Твой второй мозг может содержать разное — в том числе очень личное: здоровье, семью, финансы. **На сервер это не переезжает.** Сервер — про рабочий контур (проекты, бизнес, публичный ассистент, бот). Личное остаётся только на твоём личном компьютере, под твоим контролем.

Почему так:
- Сервер по природе «ближе к интернету» — там публичный бот, туда стучатся снаружи. Личным данным там не место.
- Бэкап идёт **с сервера на твой ПК**, а не наоборот — то есть личное с ПК на сервер само не утечёт.
- В промптах кита агенту прямо сказано: рабочий контур — да, личное (здоровье/семья/финансы) — **нет**.

Если сомневаешься, что переносить, а что нет — спроси агента: «это рабочее или личное?» — и оставь личное дома.

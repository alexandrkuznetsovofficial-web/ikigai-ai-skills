# 07 · Доступ с телефона и планшета, Tailscale (надстройка по желанию)

> **Надстройка, не обязательная.** Базовая защита у тебя уже есть: вход только по ключу, файрвол, fail2ban и аварийный вход через VNC-консоль хостера (модуль [05](05_BEZOPASNIK.md)). Этот модуль отвечает на два вопроса: «как пользоваться мозгом с телефона или планшета» и «нужен ли мне Tailscale».
>
> ⚠️ Делай только после того, как связка стоит: `brain-link verify` — 8 из 8 (модуль [06](06_QA_PROVERKA.md)).

---

## Часть A. С телефона и планшета — через бота

В связке kit 2.1 главная копия памяти — **на компьютере**, а сервер держит её копию для бота (модуль [04](04_ISTINA_I_BEKAPY.md)). Поэтому с телефона и планшета мозгом пользуются через **Telegram-бота**:

- спросить что-то из памяти — просто напиши боту;
- записать мысль — «запомни …»: заметка ляжет в `memory/inbox/` и через 5 минут будет на компьютере;
- голосом — если бот поставлен с `--voice` (модуль [03A](03A_BOT_S_NULYA.md));
- прочитать статью — пришли ссылку.

**Почему не править память на сервере с планшета** (например, через браузерный VS Code). Память на сервере — копия, её хозяин — компьютер. Правку на сервере синк сочтёт конфликтом: на сервер вернётся версия с компьютера, а твоя ляжет рядом как `….conflict-server-…` (модуль [04](04_ISTINA_I_BEKAPY.md), Часть 2). Ничего не потеряется, но разбирать придётся руками. Всё, что нужно записать с телефона, — через «запомни».

✅ **Получилось, если** с телефона ты спросил бота о своей памяти и получил ответ по делу, а «запомни: тест с телефона» через 5 минут лежит на компьютере в `memory/inbox/`.

## Часть B. Tailscale — по желанию

**Что это.** Tailscale — приложение, которое соединяет твои устройства в закрытую сеть поверх интернета. Сервер становится виден твоему компьютеру по отдельному «внутреннему» адресу.

**Нужен ли он тебе.** Скорее нет. Связка работает и без него: вход по ключу и fail2ban закрывают ssh надёжно, а белый список IP мы сознательно не ставим (модуль [05](05_BEZOPASNIK.md), Раздел 2). Tailscale имеет смысл, если ты хочешь дополнительный слой и готов держать приложение включённым на компьютере.

**Три правила, если всё-таки ставишь:**

1. **Порт 22 наружу не закрывай.** Синк, `brain-link` и закреплённый ключ сервера (`known_hosts`) настроены на адрес из Файла доступа. Закроешь порт — синк встанет, а при выключенном Tailscale ты останешься снаружи.
2. **Не включай режим `tailscale up --ssh`.** В этом режиме вход на сервер проверяет сам Tailscale, а не ssh-сервер, и запреты, которые поставил `lockdown` (вход под root, вход по паролю), на него не действуют. Обычный `tailscale up` достаточно.
3. **Ставь между `verify` и `lockdown`.** Установка программ на сервер требует прав root. После `lockdown` у Claude их нет — так и задумано (обслуживание идёт только через `sudo brain-admin` с белым списком). Уже сделал `lockdown` — ставь через VNC-консоль хостера или пропусти модуль.

| Что | Mac | Windows |
|---|---|---|
| Приложение на компьютере | App Store → Tailscale | tailscale.com → Download → Windows |
| Вход | своим аккаунтом в окне приложения, сам | так же |
| На сервере | Claude ставит по официальной инструкции Tailscale для Ubuntu и запускает `tailscale up` (без `--ssh`); ссылку для входа открываешь в браузере сам, тем же аккаунтом | то же |

**Промпт для VS Code:**
> «Поставь Tailscale на мой сервер по официальной инструкции для Ubuntu и запусти `tailscale up` без флага `--ssh`. Ссылку для входа покажи мне — открою сам. Порт 22 и ufw не трогай. В конце покажи `tailscale status`.»

✅ **Получилось, если** `tailscale status` на сервере показывает и сервер, и твой компьютер, а `brain-link status` по-прежнему зелёный (синк идёт как раньше).

## Часть C. Аварийный вход — проверь, что знаешь, где он

Если когда-нибудь потеряешь доступ по ssh (сломал настройку, забанил сам себя), выручит **VNC-консоль** в личном кабинете хостера: она открывает сервер напрямую, даже когда ssh и сеть не работают. Проверь её перед `lockdown` (модуль [01](01_ZAKAZ_VPS.md)). Пароль root — в менеджере паролей.

✅ **Получилось, если** ты открыл VNC-консоль в панели хостера и видишь приглашение входа на сервер.

Как вернуть доступ по шагам — модуль [08](08_ESLI_NE_VZLETELO.md), раздел «Доступ / самоблокировка».

## Итог модуля

- С телефона и планшета мозгом пользуешься через **бота**: вопросы, «запомни», голос, ссылки. Память правишь на компьютере.
- **Tailscale — по желанию.** Если ставишь: порт 22 не закрывать, режим `--ssh` не включать, ставить до `lockdown`.
- **Аварийный вход** — VNC-консоль хостера, проверена заранее.

```
#практика Доступ: с телефона спросил бота о своей памяти, «запомни» доехало
до компьютера за 5 минут, VNC-консоль хостера открыл и нашёл приглашение входа.
```

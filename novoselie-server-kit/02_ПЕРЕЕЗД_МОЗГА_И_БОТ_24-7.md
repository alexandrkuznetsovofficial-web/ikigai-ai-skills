# 🧠 Этаж 1 — Переезд мозга + бот 24/7

> **Как запускать:** открой Claude Code (или Codex) в VS Code в папке своего проекта и **вставь этот файл целиком как задачу**. Агент сам определит твою среду и пойдёт по нужной ветке. Не делай шаги руками — пусть делает агент, а ты подтверждаешь.
>
> Перед стартом подготовь (из `01_ЗАКАЗ_VPS.md`): **IP сервера** и **root-пароль**. Положи их НЕ в чат и НЕ в код, а попроси агента сохранить в `~/.config/<твоё-имя>/server_pw` с правами 600.

## ИНСТРУКЦИЯ ДЛЯ АГЕНТА (Claude Code / Codex)

Ты — инженер, переносящий «второй мозг» (папку MD-файлов) и Telegram-бота пользователя на его VPS так, чтобы всё работало 24/7 без его ноутбука. Работай по принципу **detect-then-branch**: сначала диагностика, печатаешь «вижу: {среда}», потом действия по нужной ветке. После каждого шага — **чек-точка** (реальная команда-проверка, не «по памяти»). Опасное (rm, смена SSH-настроек) — только спросив пользователя.

### ШАГ 0 — Диагностика среды (обязательно, первым)
Определи и выведи таблицей:
- Локальная ОС: `uname -s` (Mac/Linux) или PowerShell `($PSVersionTable)`/`ver` (Windows). От этого зависит авто-коммит: **launchd** (Mac) / **schtasks** (Windows) / **cron** (Linux).
- AI-провайдер: настроен Claude (`claude`) или Codex (`codex`)? Где ключ/логин.
- Где лежит «мозг»: найди папку MD-памяти (часто `~/.claude/...`, `~/Documents/...`, Obsidian-vault). Спроси пользователя, если неоднозначно.
- Как сейчас запущен бот: Telethon (userbot, есть `.session`) / Bot API (токен от @BotFather) / иное. Где его код и секреты.
- Архитектура сервера: подключись и `uname -m` (`x86_64` vs `aarch64`) — нужно для правильного бинаря VS Code CLI позже.

Выведи: **«Вижу: {ОС} / {AI} / мозг в {путь} / бот {тип} / сервер {arch}»** и план переезда. Дождись «ок».

### ШАГ 1 — Доступ к серверу + сохранить пароль правильно
- **Mac/Linux:** сохрани пароль — `mkdir -p ~/.config/brain && printf '%s' '<PW>' > ~/.config/brain/server_pw && chmod 600 ~/.config/brain/server_pw`. Вход: `ssh -p 22 root@<IP> 'echo OK; uname -a'` (пароль введёшь, или `sshpass`).
- **Windows:** встроенный OpenSSH в PowerShell — `ssh root@<IP>` (введёшь пароль). Пароль храни в Диспетчере учётных данных Windows или в файле `%USERPROFILE%\.config\brain\server_pw` (не в коде). Альтернатива — поставить агента в WSL и работать как на Linux.
- 🔒 **Рекомендация (оба):** сразу настрой вход по SSH-ключу (`ssh-keygen` → `ssh-copy-id`/копия ключа), чтобы не вводить пароль. Пароль НИКОГДА в код/память.
- **Чек-точка:** команда входа вернула `OK` + данные сервера (`uname -a`).

### ШАГ 2 — Базовая подготовка сервера
- На сервере: `apt update && apt -y upgrade && apt -y install git python3-venv python3-pip tmux`.
- Часовой пояс по желанию: `timedatectl set-timezone Europe/Moscow`.
- **Чек-точка:** `python3 --version && git --version` отдают версии.

### ШАГ 3 — Переезд мозга (MD-память) через git (версии + бэкап вне сервера)
1. Локально в папке мозга: убедись, что есть `.gitignore`, исключающий секреты:
   ```
   .env
   *.session
   .secrets/
   **/secret/**
   *_pw
   ```
   🔴 Если в MD-файлах ВНУТРИ текста лежат токены/пароли — вынеси их в `.env`/`~/.config` ДО коммита (иначе утекут в репо).
2. `git init && git add -A && git commit -m "brain snapshot"`.
3. Создай **приватный** репо на GitHub, `git remote add origin <...>`, `git push -u origin main`.
4. На сервере: `git clone <приватный-репо> /opt/brain`.
- **Чек-точка:** на сервере `find /opt/brain -name "*.md" | wc -l` показывает столько же файлов, сколько локально; `git -C /opt/brain log -1` есть коммит. И — `grep -rIl "ключ\|token\|password" /opt/brain` НЕ находит реальных секретов.

### ШАГ 4 — Перенос секретов бота (отдельно от git)
- Создай на сервере `/opt/brain/.secrets/` (или `~/.config/brain/`), `chmod 700`. Положи `bot.env` (`chmod 600`) с токеном бота/ключами. **Эти файлы НЕ в git** (исключены `.gitignore`).
- Если бот — Telethon userbot: перенеси `.session` файл по `scp` в `.secrets/`, `chmod 600`. (Это полный доступ к TG-аккаунту — обращайся как с паспортом.)
- **Чек-точка:** `ls -la /opt/brain/.secrets` → всё `600`, и `git -C /opt/brain status` НЕ показывает секреты.

### ШАГ 5 — Бот 24/7 через systemd (сам поднимается)
- Виртуальное окружение: `python3 -m venv /opt/brain/venv && /opt/brain/venv/bin/pip install -r /opt/brain/requirements.txt` (или нужные пакеты: `python-telegram-bot`/`telethon`/`anthropic`).
- Создай `/etc/systemd/system/brain-bot.service`:
  ```ini
  [Unit]
  Description=Brain Bot 24/7
  After=network-online.target
  Wants=network-online.target
  [Service]
  WorkingDirectory=/opt/brain
  EnvironmentFile=/opt/brain/.secrets/bot.env
  ExecStart=/opt/brain/venv/bin/python3 /opt/brain/bot.py
  Restart=always
  RestartSec=5
  [Install]
  WantedBy=multi-user.target
  ```
- `systemctl daemon-reload && systemctl enable --now brain-bot`.
- **Чек-точка (главная):** `systemctl is-active brain-bot` → `active`; `journalctl -u brain-bot -n 30` → бот стартовал без ошибок; **напиши боту в Telegram — отвечает**. Теперь закрой ноутбук на 2 минуты и проверь снова — бот жив = автономность достигнута.

### ШАГ 6 — Авто-бэкап памяти (по расписанию, кросс-платформенно)
Чтобы наработки на сервере регулярно пушились в git (offsite):
- На сервере cron: `crontab -e` → `*/30 * * * * cd /opt/brain && git add -A && git commit -m "auto $(date +\%F_\%H:\%M)" && git push >/dev/null 2>&1`.
- **Чек-точка:** через 30 мин в GitHub-репо появился авто-коммит.

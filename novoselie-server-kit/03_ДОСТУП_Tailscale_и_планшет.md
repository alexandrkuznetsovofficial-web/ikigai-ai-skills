# 🚪 НАДСТРОЙКА (рекомендуется) — Безопасный доступ к серверу

> Цель: заходить на сервер **не открывая порты в интернет** и **не запирая себя**. Даёшь этот файл агенту.
>
> ✅ **Additive:** ставится поверх Базы (`02`), ничего не переламывает — бот 24/7 как работал, так и работает; просто вход становится безопаснее. Рекомендуется всем, но технически опционально.
> ⚠️ **Гейтинг:** делай только после того, как База (`02`) завершена (бот 24/7 работает). Доступ с планшета — отдельная опция `06`.

## Почему Tailscale, а не «закрыть порт + fail2ban»
Жёсткий хардненинг (смена порта 22 + бан-машина + whitelist по IP) **уже залочивал людей наглухо**: SSH рубился на рукопожатии, а whitelist по IP ломается, когда ты на VPN (а ты на VPN). **Tailscale** даёт доступ только своим устройствам **без единого открытого порта** в интернет, поверх шифрованного WireGuard, и не зависит от меняющегося IP. Безопаснее И не запирает тебя.

## ЧАСТЬ A — Tailscale (вход с ноутбука, без открытых портов)

### На сервере (через агента)
1. Установить: `curl -fsSL https://tailscale.com/install.sh | sh`
2. Поднять с SSH-режимом: `tailscale up --ssh` → выдаст ссылку, открой её в браузере (под VPN, если из РФ), авторизуйся (Google/GitHub/email).
3. Узнать имя/адрес в сети: `tailscale status`.

### На ноутбуке
1. Поставь приложение Tailscale (Mac: App Store / brew; Windows: с сайта), залогинься **тем же аккаунтом**.
2. Теперь заходишь просто: `ssh root@<tailscale-имя-сервера>` — **без пароля и без порта**, Tailscale сам аутентифицирует.

- **Чек-точка:** `tailscale status` на сервере показывает и сервер, и твой ноут; с ноута `ssh root@<tailscale-имя>` пускает.

Это **отдельная опциональная надстройка** → файл `06_ОПЦИЯ_планшет_туннель.md`. Ставится поверх базы, ничего не переламывает. Нужен планшет — сделай 06 после этого файла; не нужен — пропусти, ничего не теряешь.

## ЧАСТЬ C — 🪜 Аварийный люк (обязательно знать ДО замков)
Если когда-нибудь потеряешь доступ (сломал настройку, забанил сам себя) — **VNC / Recovery-консоль хостера** (в панели FoxCloud) даёт вход напрямую к серверу, даже когда SSH и сеть мертвы. Это твоя страховка. **Найди эту кнопку в панели прямо сейчас и убедись, что заходит** — пока ничего не сломал.
- **Чек-точка:** открыл VNC-консоль в панели хостера → видишь приглашение логина сервера.

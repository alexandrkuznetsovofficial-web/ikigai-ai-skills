# Аудит-пак AI-Потока

Один скрипт, который смотрит, что у тебя уже собрано, и говорит, что осталось.

**Ничего не устанавливает и не ломает.** Только смотрит и рассказывает.
Пароли и токены на экран не выводятся никогда.

---

## Как запустить

### macOS

Открой **Терминал** и вставь одной строкой:

```
cd ~/Downloads/audit_pack && bash audit.sh
```

(если распаковала папку в другое место — подставь свой путь)

### Windows

Открой **PowerShell** и вставь:

```
cd $HOME\Downloads\audit_pack ; powershell -ExecutionPolicy Bypass -File .\audit.ps1
```

---

## Что будет

Скрипт пройдёт по шести блокам и по каждому пункту скажет 🟢 / 🟡 / 🔴:

1. **Твой компьютер** — система, Node, git, ssh, VS Code
2. **Claude Code** — установлен ли, вошла ли ты по подписке (а не по API-ключу)
3. **Папка второго мозга** — CLAUDE.md, память, git, скиллы
4. **Заготовки к серверу** — сервер, бот, user_id
5. **Сервер** — ОС, размер, пользователь, Claude Code, токен подписки, сервис бота, бэкапы
6. **Две живые проверки** — самое главное:
   - **мозг на сервере правда думает** из твоей подписки
   - **бот правда пишет тебе** в Telegram

В конце — твоя **ветка (A или B)**, процент готовности и два списка:
что сделать руками, и что поручить агенту.

## Что появится рядом со скриптом

| Файл | Что это |
|---|---|
| `audit_report.md` | отчёт целиком, можно перечитать или показать |
| `PROMPT_for_claude.txt` | **готовый текст**: открываешь Claude Code в папке мозга и вставляешь. Агент доделает остальное |

---

## Порядок работы

1. Запустила аудит.
2. Сделала пункты «руками» (их нельзя поручить агенту: заказать сервер, создать бота, войти по подписке).
3. Открыла Claude Code в папке мозга, вставила текст из `PROMPT_for_claude.txt`.
4. Когда агент закончил — **запустила аудит ещё раз**.

Готово, когда в блоке 6 оба пункта зелёные:

```
🟢 МОЗГ НА СЕРВЕРЕ ДУМАЕТ и отвечает из твоей подписки
🟢 Бот написал тебе в Telegram
```

---

## Если сервер не пускает

Аудит скажет: «сервер не пускает без пароля». Это нормально на первый раз.
Выполни один раз (подставь свои IP и порт — они в подсказке скрипта):

```
ssh-copy-id -p 22 root@<IP>
```

Введёшь пароль один раз — дальше вход без пароля, и скрипт увидит сервер.

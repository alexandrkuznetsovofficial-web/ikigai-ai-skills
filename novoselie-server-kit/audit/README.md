# Аудит-пак AI-Потока

Один скрипт, который смотрит, что у тебя уже собрано, и говорит, что осталось.

**Цель (kit 2.1) — связка «как у Александра».** Компьютер — мастерская: здесь главная копия
второго мозга, здесь ты правишь память и ставишь скиллы. Сервер вне РФ — база 24/7: бот в Telegram
из твоей подписки, утренний брифинг, копия памяти. Синк каждые ~5 минут. Ставит всё скилл
`brain-link`, приёмка — `brain-link verify` (9 проверок).

**Ничего не устанавливает и не ломает.** Только смотрит и рассказывает.
Пароли и токены на экран не выводятся никогда.

---

## Как запустить

Переходить в папку второго мозга **не нужно**: скрипт находит её сам по профилю
`~/.claude/ikigai_env.json` (Windows: `%USERPROFILE%\.claude\ikigai_env.json`, его записывает скилл
`ikigai-preflight`; в выпускном паке он лежит в корне архива). Профиля нет — скрипт посмотрит текущую папку и привычные
места. Не нашёл — допиши путь к папке мозга в конце команды: `bash audit.sh ~/SecondBrain`
(Windows: `.\audit.ps1 C:\SecondBrain`).

### macOS

Открой **Терминал** и вставь одной строкой:

```
cd ~/Downloads/audit_pack && bash audit.sh
```

(если распаковала папку в другое место — подставь свой путь; в выпускном паке скрипт лежит в
`AI_Potok_Graduation_Pack_v2/novoselie-server-kit/audit`)

### Windows

Открой **PowerShell** и вставь:

```
cd $HOME\Downloads\audit_pack ; powershell -ExecutionPolicy Bypass -File .\audit.ps1
```

## Что будет

Скрипт пройдёт по семи блокам и по каждому пункту скажет 🟢 / 🟡 / 🔴:

1. **Твой компьютер** — система, Node, git, ssh, VS Code
2. **Claude Code** — установлен ли, вошла ли ты по подписке (а не по API-ключу)
3. **Папка второго мозга** — CLAUDE.md, память, git, скиллы
4. **Заготовки к серверу** — сервер, бот, user_id
5. **Сервер** — ОС, размер, пользователь, Claude Code, токен подписки, сервис бота, бэкапы
6. **Две живые проверки** — самое главное:
   - **мозг на сервере правда думает** из твоей подписки
   - **бот правда пишет тебе** в Telegram
7. **Второй мозг по эталону** (kit 2.0, точки 13–23) — проекты отделены от ядра, размер
   CLAUDE.md, здоровье скиллов и их версия (`kit_version`), нет ли личного в облаке, стадии
   заметок, граф связей, правило двойной ошибки, журнал обещаний, свежая дистилляция,
   брифинг в расписании, которое переживает сон (launchd на Mac, Планировщик заданий на Windows)

В конце — твоя **ветка (A или B)**, процент готовности и два списка:
что сделать руками, и что поручить агенту. Блок 7 считается отдельно и **только из применимых**:
«есть X из N применимых». Точка, которой у тебя нет смысла быть (например, расписание брифинга,
когда брифинг ты зовёшь словами и скрипта нет), помечена ⚪ «не применимо» и в счёт не идёт.
Блок 7 не меняет ветку и процент готовности сервера.

Блок 7 видит, **есть ли** файл, поле или задача. **Работает ли** это на деле — проверяет скилл
`second-brain-audit` (он лежит в `skills/`): сверяет со свежим эталоном из 23 точек,
предлагает план и ничего не меняет, пока ты не скажешь «делай». Обычно план — поставить скилл
`memory-upgrade` (в выпускном паке — папка `memory-upgrade/` в корне).

**Выпускной чекап** — два отдельных запуска скилла:
- «выпускной чекап» — прогон **до**: отчёт в `~/.claude/audit/checkup_<дата>_before.md`, рядом эталон;
- после достройки — «выпускной чекап, прогон после»: отчёт `_after.md` и итог для слайда
  «было X из N применимых → стало Y из N».

Если до «после» не дошло — слайд строится из одного прогона «до» («старт»).

## Порядок работы

1. Запустила аудит.
2. Сделала пункты «руками» (их нельзя поручить агенту: заказать сервер вне РФ,
   создать бота, узнать user_id, ввести команду шага `keys`, выпустить токен
   подписки через `brain-link put-token claude`).
3. Открыла Claude Code в папке мозга, вставила текст из `PROMPT_for_claude.txt` (или `MASTER_PROMPT.txt`).
   Агент ставит связку шагами `brain-link`, а не собирает сервер и бота вручную.
4. Когда агент закончил — `brain-link verify` и **ещё раз аудит**.

Готово, когда `brain-link verify` показал **все 9 проверок (а)–(и) зелёными**: правка доезжает до сервера по расписанию,
«запомни» из бота за 5 минут лежит у тебя в `memory/inbox/`, личного на сервере нет, бот молчит чужим.

## Если сервер не пускает

Аудит скажет: «сервер не пускает без пароля». Это нормально на первый раз.
Попроси Claude: «Запусти brain-link, шаг keys». Пароль root он возьмёт из Файла доступа сам
(впиши его туда в блокноте, строка PASSWORD) и положит ключ на сервер — в терминал ничего
вводить не нужно. Дальше вход по ключу, и скрипт увидит сервер.

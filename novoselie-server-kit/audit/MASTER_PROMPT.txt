════════════════════════════════════════════════════════════════════
ЭТАП 4. РАСКАТКА — шаги brain-link по согласованному плану
════════════════════════════════════════════════════════════════════

Работает связка: devops запускает шаги, secops проверяет замки, code-reviewer
смотрит всё, что пишется сверх стандартного, cto держит план и отвечает за результат.
Сервер и бота НЕ собираем вручную — только шагами brain-link:

  detect → keys → harden → claude → put-token claude (Я САМА) →
  init (ветка A) или adopt (ветка B) → schedule → bot [--voice] → verify → lockdown

  detect     — смотрит систему, ssh, Python, Файл доступа, сервер, часы
  keys       — ключ ed25519 + одна команда для меня, закреплённый ключ сервера
  harden     — пользователь brain, swap, ufw (только ssh), fail2ban, обновления,
               часы, brain-admin. Без белого списка IP
  claude     — Claude Code под brain, проверка «ANTHROPIC_API_KEY нет»
  init/adopt — первая копия памяти и скиллов на сервере; adopt выключает старое
               ночное зеркало и снимки, коммит «до», личное с сервера — домой
  schedule   — синк каждые 5 минут (launchd на Mac / Планировщик на Windows),
               сразу пробный запуск и чтение журнала
  bot        — стандартный бот + брифинг с сервера; старый бот только отключает
  verify     — 8 проверок
  lockdown   — только после зелёного verify, при открытом втором терминале
               и проверенном VNC; «да» дважды

Инструкции — модули кита, читай модуль ПЕРЕД шагом:
https://github.com/alexandrkuznetsovofficial-web/ikigai-ai-skills/tree/main/novoselie-server-kit

  01_ZAKAZ_VPS.md         — сервер вне РФ, Файл доступа
  02_YADRO_PEREEZD.md      — что делают keys, harden, claude, put-token, init
  03A_BOT_S_NULYA.md       — стандартный бот: brain-link bot
  04_ISTINA_I_BEKAPY.md    — где что живёт, конфликты, бэкапы, adopt, пауза синка
  05_BEZOPASNIK.md         — harden и lockdown, аварийный вход
  06_QA_PROVERKA.md        — 8 проверок verify
  08_ESLI_NE_VZLETELO.md   — поломки связки

ЧТО ЗНАТЬ, ЕСЛИ ДЕЛАЕШЬ ЧТО-ТО СВЕРХ brain-link:
1. К модели ходим только через headless-CLI: claude -p "вопрос".
   НЕ через api.anthropic.com с подписочным токеном в заголовке — этот путь
   не поддерживается и отдаёт 429 постоянно.
2. ANTHROPIC_API_KEY не должен существовать нигде. Если он есть, он ПЕРЕБИВАЕТ
   подписку, и появляется «Credit balance is too low» — это не поломка подписки,
   а уход на платный счётчик.
3. Перед массовой правкой памяти — brain-sync pause, после — brain-sync resume
   и brain-sync run.

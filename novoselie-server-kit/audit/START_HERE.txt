С ЧЕГО НАЧАТЬ
=============

У тебя MAC?
-----------
Открой программу «Терминал» (Cmd+Пробел → напиши «Терминал» → Enter)
и вставь туда одну строку:

    cd ~/Downloads/audit_pack && bash audit.sh


У тебя WINDOWS?
---------------
Нажми «Пуск» → напиши «PowerShell» → открой его
и вставь туда одну строку:

    cd $HOME\Downloads\audit_pack ; powershell -ExecutionPolicy Bypass -File .\audit.ps1


Если папку распаковала не в «Загрузки» — подставь свой путь вместо ~/Downloads.

В папку второго мозга переходить НЕ нужно: скрипт находит её сам по профилю
~/.claude/ikigai_env.json (его записывает скилл ikigai-preflight).
Не нашёл — допиши путь к папке мозга в конце команды, например:
    Mac:     bash audit.sh ~/SecondBrain
    Windows: powershell -ExecutionPolicy Bypass -File .\audit.ps1 C:\SecondBrain
Если это выпускной пак — папка со скриптом лежит глубже:
    Mac:     ~/Downloads/AI_Potok_Graduation_Pack_v2/novoselie-server-kit/audit
    Windows: $HOME\Downloads\AI_Potok_Graduation_Pack_v2\novoselie-server-kit\audit

Дальше скрипт всё скажет сам. Он ничего не ломает и не устанавливает — только смотрит.
Подробности — в файле README.md.

Блок 7 «Второй мозг по эталону» — новый (kit 2.0): сверяет твою память с точками 13–23
эталона и показывает «есть / частично / нет». Счёт — только из применимых: то, чего у тебя
нет смысла иметь (например, расписание брифинга без скрипта брифинга), помечено «не применимо».
Разбирает и чинит это скилл second-brain-audit из папки skills — и только после твоего «делай».
Перед выпуском скажи ему «выпускной чекап» (прогон до), после достройки —
«выпускной чекап, прогон после».

РЕКОМЕНДУЕМЫЙ ПУТЬ: пусть всё сделает агент
--------------------------------------------
Тогда в терминал ходить почти не придётся.

1. Открой VS Code в папке своего второго мозга и открой в нём Claude Code.
2. Вставь туда текст из файла MASTER_PROMPT.txt.
3. Дальше агент сам: поставит техническую команду из папки skills, прогонит аудит,
   соберёт план и покажет его тебе. Пока ты не скажешь «делай» — он ничего не меняет.

От тебя четыре шага, которые он сделать не может:
заказать сервер, создать бота, узнать свой user_id и выпустить токен подписки.


ЧТО В ПАПКАХ
------------
skills/ — скиллы, которые копируются в ~/.claude/skills/:
          cto (главный) · secops (безопасность) · devops (сервер) ·
          code-reviewer (вычитка) · anthropic-academy · second-brain-audit
          В выпускном паке рядом, в корне архива: ikigai-preflight/ (профиль
          компьютера), project-splitter/ (выносит проект из папки мозга),
          meeting-2-3/orchestrator.md (вызывает нужного специалиста)
docs/   — инструкции, на которые опирается агент: бэкапы, утренний брифинг,
          оркестратор, сентябрьский апгрейд системы
MASTER_PROMPT.txt — текст для агента (рекомендуемый путь выше)

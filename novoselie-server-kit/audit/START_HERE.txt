С ЧЕГО НАЧАТЬ
=============

У тебя MAC?
-----------
Открой программу «Терминал» (Cmd+Пробел → напиши «Терминал» → Enter)
и вставь туда одну строку:

    cd ~/Downloads/audit_pack && bash audit.sh


У тебя WINDOWS?
---------------
Нажми «Пуск» → напиши «PowerShell» → открой его
и вставь туда одну строку:

    cd $HOME\Downloads\audit_pack ; powershell -ExecutionPolicy Bypass -File .\audit.ps1


Если папку распаковала не в «Загрузки» — подставь свой путь вместо ~/Downloads.

Дальше скрипт всё скажет сам. Он ничего не ломает и не устанавливает — только смотрит.
Подробности — в файле README.md.

ХОЧЕШЬ, ЧТОБЫ ВСЁ СДЕЛАЛ АГЕНТ?
--------------------------------
Тогда в терминал вообще не ходи. Открой VS Code в папке своего второго мозга,
открой Claude Code и вставь туда текст из файла MASTER_PROMPT.txt.
Дальше агент сам скачает аудит, запустит его, прочитает отчёт и построит остальное.
От тебя останутся четыре шага, которые он сделать не может:
заказать сервер, создать бота, узнать свой user_id и выпустить токен подписки.

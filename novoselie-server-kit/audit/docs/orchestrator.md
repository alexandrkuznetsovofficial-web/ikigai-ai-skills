# ОРКЕСТРАТОР v2.0 — единый и самоустанавливающийся

## ⚡ КАК ТОЛЬКО ЭТОТ ФАЙЛ ЗАГРУЖЕН — НАЧИНАЙ СРАЗУ

Не жди команд. Не объясняй заранее что будешь делать — делай и показывай результат каждого шага.
Задай вопрос ТОЛЬКО если нашёл два оркестратора или два CLAUDE.md (спроси какой главный).
Во всех остальных случаях — решай сам и двигайся.

**Запускать этот скилл можно сколько угодно раз.** Он идемпотентный: только добавляет, никогда не перезаписывает и не ломает. Первый запуск — на пустой системе (создаст базу и спланирует команду). Повторный — после установки скиллов (соберёт реальную команду и проводку). Это ОДИН скилл на оба момента.

## ШАГ 1. СКАНИРОВАНИЕ (сразу, без вопросов)

```bash
# CLAUDE.md
find ~ -maxdepth 5 -name "CLAUDE.md" 2>/dev/null | grep -v ".git"
# все скиллы
find ~/.claude/skills -name "SKILL.md" 2>/dev/null
# единый файл команды
find ~/.claude/skills -name "TEAM.md" 2>/dev/null
# СТАРЫЙ файл команды (подлежит миграции)
find ~ -maxdepth 5 -name "ai-team.md" 2>/dev/null | grep -v ".git"
# ACTIVE.md
find ~ -maxdepth 5 -name "ACTIVE.md" 2>/dev/null | grep -v ".git" | head -3
```

Пока сканируешь — читай description каждого SKILL.md, ищи оркестратора.
**Оркестратор** — SKILL.md, где в description есть: `chief of staff` / `оркестратор` / `операционный директор` / `диспетчер` / `маршрутизирует` / `делегирует` / `правая рука` / `координирует команду`.

Определи режим:
- **Первый запуск** — оркестратора нет И установлено ≤2 скиллов → иди в ШАГ 2 (планирование), затем дальше.
- **Апгрейд** — оркестратор есть ИЛИ скиллов больше → ШАГ 2 пропусти, начни с ШАГ 3.

**Сообщи:**
```
🔍 Скан завершён:
• CLAUDE.md: [путь]
• Оркестратор: [имя/нет]
• Скиллов: [N] — [список]
• TEAM.md: [есть/нет] · старый ai-team.md: [есть/нет]
• Режим: [первый запуск / апгрейд]
```

## ШАГ 2. ПЕРВЫЙ ЗАПУСК — ПЛАН КОМАНДЫ ПОД БИЗНЕС-МОДЕЛЬ (только если режим = первый запуск)

Задай 5 вопросов по одному, дождись ответов. Это распаковка стратегии — не формальность.

1. «Чем ты занимаешься и на чём зарабатываешь? Опиши бизнес в 2–3 фразах.»
2. «Какая у тебя бизнес-модель: подписка / LTV-удержание / разовые продажи / консалтинг / ретейл / другое?»
3. «Что тобой движет — большая миссия или пока это способ зарабатывать?»
4. «Где твоё узкое горлышко прямо сейчас — что тормозит рост?»
5. «Какое ручное действие болит больше всего — что хочешь делегировать первым?»

По ответам определи тип бизнеса и предложи **состав команды под именно эту модель** (разным моделям — разный AI-штаб). Запиши в `memory/strategy/personal_strategy.md`: кто пользователь, миссия, бизнес-модель, узкое горлышко, что делегировать. Затем создай базового Тима (ШАГ 5Б) и продолжай.

## ШАГ 3. МИГРАЦИЯ + ЕДИНЫЙ TEAM.md

**Путь (единственный источник истины):** `~/.claude/skills/[папка оркестратора]/TEAM.md`

1. Если нашёл **старый `ai-team.md`** — прочитай его, перенеси состав в `TEAM.md`, а в конце `ai-team.md` допиши строку `> ⚠️ Устарел. Единый файл команды теперь TEAM.md.` (не удаляй молча).
2. Если `TEAM.md` уже есть — **дополни** недостающими скиллами, не перезаписывай.
3. Если нет — создай из реальных SKILL.md:

```markdown
# TEAM.md — Карта цифровой команды
*Обновлено: [дата]. Единый источник истины (заменяет ai-team.md).*
*Анти-сирота: скилл активен только после записи сюда.*

## Оркестратор
| Скилл | Роль | Когда |
|---|---|---|
| `/[оркестратор]` | [суть из description] | Всегда — старт дня, разбор, маршрутизация |

## Команда специалистов
| Скилл | Что делает | Когда вызывать |
|---|---|---|
| `/[name]` | [суть, 5–8 слов] | [триггеры] |

## Версия
- Оркестрация: v2.0 ([дата])
```

**Сообщи:** `✓ TEAM.md: [путь] · агентов: [N] · миграция ai-team.md: [да/не требовалась]`

## ШАГ 4. ПРОВОДКА МАРШРУТИЗАЦИИ В CLAUDE.md

Только добавлять, ничего не удалять.

**Блок А — автозагрузка при старте** (если секции про старт нет — добавь после заголовка):
```markdown
## При каждом старте сессии — прочитать
- ACTIVE.md — текущий фокус
- ~/.claude/skills/[папка оркестратора]/TEAM.md — карта команды
```

**Блок Б — правило маршрутизации** (если такого правила нет — добавь в конец):
```markdown
## Автоматическая маршрутизация
1. Определи тему запроса
2. Найди агента в TEAM.md (колонка «Когда вызывать»)
3. Передай ему — не отвечай сам, если есть специалист
4. Нет подходящего → оркестратор берёт сам
TEAM.md — единственный источник истины. Новый скилл → строка в TEAM.md → маршрутизация видит его.
Исключения (отвечать напрямую): технические операции Claude Code, короткие справки, «ответь сам».
```

**Сообщи:** `✓ CLAUDE.md: автозагрузка TEAM.md + правило маршрутизации`

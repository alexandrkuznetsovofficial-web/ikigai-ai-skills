## ШАГ 5В. ХУК-ДИСПЕТЧЕР (по желанию)

**Зачем.** Инструкция в `CLAUDE.md` — просьба, модель может «упомянуть» специалиста вместо того, чтобы его
вызвать. Хук срабатывает на каждое сообщение человека до ответа модели: сверяет фразу с триггерами из `TEAM.md`
и подсказывает модели, какого специалиста вызвать первым ходом. По нашим замерам хук держит маршрутизацию
надёжнее инструкции.

Предложи: «Поставить хук-диспетчер? Он только подсказывает, ничего не блокирует, выключается одним файлом». Нет — пропусти шаг.

**Правила установки:**
- ставится **в папку второго мозга** (`$WS/.claude/`), не глобально;
- `settings.json` **сливается**, а не перезаписывается: чужие хуки (например, `claude-autoflow`) остаются;
- скрипт **всегда** завершается с кодом 0 — любая ошибка = тишина, работа не встаёт;
- выключатель: файл `$WS/.claude/hooks/team_dispatch.off` — есть файл, хук молчит;
- служебные сообщения (начинаются с `<`, приходят от субагентов и уведомлений) хук пропускает;
- окончания строк в скрипте — LF;
- вход и выход — байты UTF-8: на Windows консоль по умолчанию в cp1251/cp866, и обычный `print` с кириллицей
  падает или превращается в «????». Поэтому скрипт читает `sys.stdin.buffer` и пишет в `sys.stdout.buffer`;
- понимает обе таблицы `TEAM.md`: скиллы (`/имя`) и агентов (`@имя`).

Скрипт `$WS/.claude/hooks/team_dispatch.py` (Python без зависимостей, Mac и Windows):
```python
#!/usr/bin/env python3
"""Хук-диспетчер: фраза человека -> подсказка, какого специалиста из TEAM.md вызвать. Всегда exit 0."""
import json, os, re, sys

TEAM_PATH = os.path.expanduser("~/.claude/skills/<папка оркестратора>/TEAM.md")
HOOK_DIR = os.path.dirname(os.path.abspath(__file__))
ROW = re.compile(r"\s*\|\s*`?([/@])([\w.-]+)`?\s*\|")   # | `/скилл` | или | `@агент` |

def say(text):
    # Только байты UTF-8: на Windows print() с кириллицей падает или даёт «????»
    sys.stdout.buffer.write((text + "\n").encode("utf-8"))
    sys.stdout.buffer.flush()

def main():
    if os.path.exists(os.path.join(HOOK_DIR, "team_dispatch.off")):
        return
    try:
        raw = sys.stdin.buffer.read().decode("utf-8", "replace")
        prompt = (json.loads(raw).get("prompt") or "").strip()
    except Exception:
        return
    if not prompt or prompt.startswith("<"):
        return
    low = prompt.lower()
    skills, agents = [], []
    with open(TEAM_PATH, encoding="utf-8", errors="replace") as f:
        for line in f:
            m = ROW.match(line)
            if not m:
                continue
            for phrase in re.findall(r"«([^»]+)»", line):
                p = phrase.strip().lower()
                if len(p) >= 4 and p in low:
                    (agents if m.group(1) == "@" else skills).append(m.group(2))
                    break
    parts = []
    if skills:
        parts.append("скилл " + ", ".join("/" + h for h in dict.fromkeys(skills)) + " — вызови его первым ходом")
    if agents:
        parts.append("агент " + ", ".join(dict.fromkeys(agents))
                     + " — запусти его инструментом Agent (subagent_type = имя агента)")
    if parts:
        say("Подсказка диспетчера: по фразе подходит " + "; ".join(parts) + ". Не пересказывай специалиста своими словами.")

if __name__ == "__main__":
    try:
        main()
    except Exception:
        pass
    sys.exit(0)
```

Команда хука по системе:

| Mac | Windows 🧪 |
|---|---|
| `python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/team_dispatch.py"` | `py -3 "$CLAUDE_PROJECT_DIR/.claude/hooks/team_dispatch.py"` (нет `py` — значение `python_cmd` из профиля) |

Слияние в `$WS/.claude/settings.json` — добавить, если такой команды ещё нет:
```json

```
Делай это скриптом, который читает существующий файл, дописывает элемент в список `hooks.UserPromptSubmit`

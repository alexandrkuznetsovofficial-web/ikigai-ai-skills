# 🏠 Новоселье: компьютер — мастерская, сервер — база

**Что это.** Кит, после которого твой второй мозг живёт так же, как у Александра. **Компьютер** (Mac или Windows) — мастерская: здесь Claude Code в VS Code видит твои файлы, здесь ты правишь память и ставишь скиллы. **Сервер** (вне РФ) — база: на нём 24/7 работает твой Telegram-бот, оттуда приходит утренний брифинг, там лежит копия памяти. Каждые 5 минут они сверяются сами.

**Для кого.** Для предпринимателя, не технаря. Mac или Windows. Всю техническую работу делает Claude Code и готовый скилл-установщик `brain-link`, а ты заказываешь, принимаешь и пару раз вводишь пароль сам.

> Версия кита 2.1. Если ты уже переезжал по старой схеме («главная копия на сервере, компьютер — окно, ночное зеркало»), не переживай: шаг `brain-link adopt` переводит на новую схему без потерь (модуль [00](00_START_I_AUDIT.md), ветка B).

## 🧭 Схема «база и мастерская»

```
КОМПЬЮТЕР — мастерская                          СЕРВЕР вне РФ — база (Ubuntu 24.04)
Claude Code видит твои файлы                    бот в Telegram 24/7, утренний брифинг
memory/ и скиллы правишь здесь   ── каждые 5 мин ──►  копия памяти и скиллов
memory/inbox/, memory/dialogues/ ◄── каждые 5 мин ──  бот записал «запомни …» и журнал
```

- **Правишь на компьютере.** Сервер получает копию сам, через 5 минут.
- **Бот пишет только в две папки:** `memory/inbox/` (твои «запомни …») и `memory/dialogues/` (журнал разговоров). Они сами приезжают на компьютер.
- **Личное не уезжает никогда:** `personal/`, `private/`, `secret…`, `sessions/` исключены в обе стороны.
- **Подписка одна** — Claude на компьютере и бот на сервере работают из неё оба.

**Как запустить шаг.** Скажи Claude Code: *«Запусти brain-link, шаг detect»* — дальше он всё делает сам. Ниже команды, которые Claude выполняет у себя. Тебе они нужны только в двух шагах, где команду вводишь ты сам (`keys` и `put-token`):

| Что | Mac | Windows |
|---|---|---|
| Где лежит скилл | `~/.claude/skills/brain-link/` | `%USERPROFILE%\.claude\skills\brain-link\` |
| Запуск шага | `python3 ~/.claude/skills/brain-link/scripts/brain_link.py <шаг>` | `py -3 "$env:USERPROFILE\.claude\skills\brain-link\scripts\brain_link.py" <шаг>` (в PowerShell) |
| Файл доступа | `~/.config/brain/server_access` | `%USERPROFILE%\.config\brain\server_access` |
| Расписание синка | launchd `com.ikigai.brain-sync` | Планировщик задач, задача `Ikigai brain-sync` |

✅ **Получилось, если** `brain-link verify` показал 8 зелёных из 8, бот ответил тебе в Telegram, а заметка «запомни …» через 5 минут лежит у тебя на компьютере в `memory/inbox/`.

## 🔒 Четыре правила на всё время

- **Данные сервера — в Файл доступа**, не в чат: `~/.config/brain/server_access` (Windows: `%USERPROFILE%\.config\brain\server_access`). Ключи: `SERVER_IP`, `SERVER_USER`, `SERVER_PORT`, `BOT_TOKEN`, `USER_ID` и временно `PASSWORD` (удаляется после `lockdown`). Файл никому не пересылай.
- **Токен подписки в файлы и в чат не пишем.** Ты сам запускаешь `brain-link put-token claude`: ввод скрыт, токен сразу уходит на сервер.
- **Личное** (здоровье, семья, финансы) на сервер не едет: `personal/`, `private/`, `secret…`, `sessions/` синк пропускает в обе стороны.
- **Правим на компьютере.** Бэкап — локальная история git на компьютере (скилл `auto-commit-backup`); сервер можно пересобрать за один шаг `brain-link init`. Память в GitHub не отправляем никогда, даже в приватный репозиторий: GitHub — только для кода и скиллов.

# 🏠 Новоселье: переезд второго мозга на сервер

**Что это.** Готовый кит, чтобы твой AI-ассистент (Claude Code / Agent SDK) переехал на сервер и работал **24/7**, а компьютер и телефон стали окнами к нему. Всю техническую работу делает агент — ты выступаешь заказчиком и приёмщиком.

**Для кого.** Для предпринимателя, не технаря. Универсально: **Windows / macOS / Linux**. Работает и если у тебя ещё нет сервера (соберём с нуля), и если сервер уже есть, но настроен иначе (аудит → донастройка).

---

## 🚀 С чего начать (1 шаг)

Открой свой **Claude Code** (в терминале или внутри VS Code) и вставь этот текст. Он **ничего не меняет** — только смотрит, как у тебя всё настроено, и выдаёт персональный план:

```text
Ты — мой технический помощник. Мы готовимся к «переезду второго мозга на сервер»:
цель — чтобы Claude Code (Agent SDK) жил на VPS и работал 24/7, а мой компьютер и телефон
были окнами к нему. Сейчас нужен АУДИТ моей ситуации. Ничего не меняй — только исследуй.

Правила безопасности (соблюдай всегда): секреты не выводи в чат (только путь к файлу);
секреты храни по стандарту ОС — Windows: %USERPROFILE%\.secrets\<имя-сервиса>\ (доступ только
владельцу) или Windows Credential Manager; macOS: ~/.config/<имя-сервиса>/ (chmod 600) или
Keychain; Linux: ~/.config/<имя-сервиса>/ (chmod 600). Общий принцип: не в чат, не в код,
не в git. Личное (здоровье/семья/финансы) на сервер не переносим.
Если для шага понадобятся IP/логин/пароль сервера или другой секрет — НЕ проси их в чат:
создай/открой мне «Файл доступа» (macOS/Linux: ~/.config/brain/server_access; Windows:
%USERPROFILE%\.secrets\brain\server_access.txt), я впишу значения и скажу «готово»;
проверь, что значения настоящие (не пустые, без < >, IP не 1.2.3.4 и не 127.0.0.1),
и дальше работай сам, повторно не спрашивая.

Проверь и дай короткий факт по каждому пункту:
1. ОС и версия, оболочка терминала.
2. Claude Code: установлен ли, версия, как аутентифицирован (подписка/API-ключ).
3. VPS: есть ли сервер (глянь ~/.ssh/config и следы SSH); если есть — ОС, что запущено,
   настроен ли там Claude Code. Если нет — скажи «VPS не обнаружен».
4. Telegram-бот: есть ли, как называется, что умеет, где код и где токен (путь, не токен),
   где запущен (ПК/сервер).
5. Где сейчас «истина» (второй мозг): на ПК или на сервере; есть ли синхронизация/бэкапы.
6. Сервисы/инструменты: MCP, скрипты, cron/Планировщик — что уже настроено.
7. Секреты: где хранятся ключи (код/.env/~/.config/env-переменные), безопасно ли —
   но НЕ показывай значения.

Вывод:
A) Ветка A (VPS нет — строим с нуля) или Ветка B (VPS есть — донастраиваем). Обе → один результат.
B) Персональный план шагов под мою ситуацию + какие модули кита мне актуальны.
C) Не более 3 уточняющих вопросов, только если без них план не собрать.

Пиши тёпло, без жаргона. Я предприниматель, не технарь.
```

Дальше агент сам скажет, какая у тебя ветка (A или B) и по каким модулям идти.

## 🔒 Четыре правила на всё время

- IP/логин/пароль сервера → в **Файл доступа** (`~/.config/brain/server_access`; Windows: `%USERPROFILE%\.secrets\brain\server_access.txt`): агент создаёт и открывает файл, ты вписываешь данные, говоришь «готово» — дальше он берёт их оттуда сам. **В чат — никогда.** Полный промпт — в `01_ЗАКАЗ_VPS.md` и в Глоссарии.
- Секреты (токены/пароли/ключи) → в защищённое хранилище **по стандарту твоей ОС** (все три варианта — «по стандарту», не хуже): **Windows** — `%USERPROFILE%\.secrets\<имя-сервиса>\` (доступ только владельцу) или Windows Credential Manager; **macOS** — `~/.config/<имя-сервиса>/` (chmod 600) или Keychain; **Linux** — `~/.config/<имя-сервиса>/` (chmod 600). Общий принцип везде: **не в чат, не в код, не в git.**
- Личное (**здоровье, семья, финансы**) → на сервер **не** переносим. Сервер — рабочий контур.
- Истина → на **сервере**; ПК и телефон → окна. Бэкап → **сервер → ПК**.

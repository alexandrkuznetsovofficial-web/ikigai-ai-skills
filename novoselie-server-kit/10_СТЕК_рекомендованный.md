# 🧰 Рекомендованный стек — проверенные связки под нас

> Подобрано под нашего участника: предприниматель, не сисадмин, работает через **Claude Code / Codex в VS Code**, на **Windows или Mac**, сидит на **VPN** (важно для РФ). Каждый инструмент — зрелый, с большим комьюнити, бесплатный/almost free. Два трека: **A — простой (всем)**, **B — про (по желанию)**.

## Карта «потребность → инструмент»
| Потребность | Берём (Трек A) | Почему именно это | Трек B (про) |
|---|---|---|---|
| Бот/мозг работает 24/7 | **systemd** (встроен в Ubuntu) | стандарт Linux, `Restart=always` = сам поднимается после краша/перезагрузки | pm2 (если стек на Node) |
| Безопасный вход на сервер | **Tailscale** | доступ **без открытых портов**, поверх WireGuard, **работает на VPN/NAT**, не нужно возиться с ключами и fail2ban | Headscale (полностью свой control-server) |
| Редактор с планшета/телефона | **VS Code `code tunnel`** → vscode.dev | без домена и прокси, через твой GitHub-аккаунт, дружит с VPN | code-server / OpenVSCode Server (свой домен+SSL) |
| Память (твои MD) — версии + бэкап вне сервера | **git + приватный GitHub-репо** | история изменений + offsite-копия одним `git push`; Obsidian-совместимо | restic / borg (шифрованные снапшоты в облако) |
| Веб-эндпоинт (если нужен сайт/вебхук) | **Caddy** | авто-HTTPS «из коробки», конфиг в 1 строку — проще nginx для новичка | nginx (если уже умеешь) |
| Секреты (ключи, токены) | **`.env` 600 + `~/.config/`** | минимум зависимостей, ничего не утечёт в git/RAG | sops + age (шифрованные секреты в репо) |
| Сам «оператор» сервера | **Claude Code / Codex на сервере** | ты не пишешь команды руками — агент делает; в духе «autoresearch» Карпаты | — |
| Резервный вход, если всё сломал | **VNC / Recovery-консоль хостера** (FoxCloud) | работает, даже когда SSH/сеть мертвы — это твоя страховка от самоблокировки | — |

## Почему именно так (ключевые решения)
- **Tailscale вместо «закрыть порт 22 + fail2ban + whitelist по IP».** Старый путь уже **залочивал людей наглухо** (бан-машина рубила SSH на рукопожатии; whitelist по IP ломается на VPN). Tailscale закрывает доступ для чужих, **не открывая ничего в интернет**, и не зависит от твоего меняющегося IP за VPN. Это и безопаснее, и не запирает тебя. ([Tailscale SSH](https://tailscale.com/docs/features/tailscale-ssh))
- **code tunnel для планшета** — без домена/сертификатов, авторизация через GitHub, проходит сквозь VPN. ([VS Code Tunnels](https://code.visualstudio.com/docs/remote/tunnels))
- **git + GitHub для памяти** — твои MD получают историю + копию вне сервера. Если сервер умрёт — мозг цел в репо. (Правило: **секреты в репо не коммитим** — для них `.env`/`~/.config`.)
- **Caddy** берём только если реально нужен веб; боту с Telegram он не обязателен.

## Философия (Карпаты-aligned — честно)
У Андрея Карпаты **нет** готового «стека бота-на-сервере» — у него **подход**: своё, минимальное, хакабельное, под твоим контролем (`nanochat` — собери свой ChatGPT за $100; `autoresearch` — агент сам крутит цикл ночью). Мы берём этот дух: не арендованная платформа-чёрный-ящик, а **твой дом**, где агент работает на тебя 24/7, а ключ — у тебя.

## Что НЕ берём (чтобы не усложнять новичку)
- Тяжёлые self-host PaaS (Coolify/CapRover) — мощно, но избыточно для одного бота. Это уже Трек B для тех, кто захочет «как у больших».
- Docker на старте — не обязателен; systemd + venv проще и прозрачнее для первого переезда.
- Kubernetes — нет.

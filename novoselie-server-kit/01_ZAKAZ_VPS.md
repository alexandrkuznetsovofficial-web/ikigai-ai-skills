# 🖥 Пре-ворк — Заказать VPS (до урока!)

> Делай **за 2–4 дня до урока**: поддержке хостера нужен запас. К уроку сервер должен быть у тебя на руках, а Файл доступа — заполнен.

## Почему сервер вне РФ

Сервер нужен **за пределами России**. С российского хостинга Claude и Telegram API недоступны: бот не сможет ни думать, ни отвечать. Наш стандарт — Нидерланды.

## Самый простой путь (для нетехнического) — тикет в FoxCloud

Не регистрируйся сам через формы (в Потоке 1 на этом застревали). Напиши в поддержку **FoxCloud** — сервер подберут и поднимут живые люди.

> 🌐 **Сайт для оплаты из РФ (рубли/СБП): [ru.foxcloud.net](https://ru.foxcloud.net).** Есть и международный foxcloud.net с ценами в долларах. Видишь цены в $ — переходи на `ru.foxcloud.net`.

**В заявке укажи:**
- Кодовое слово: **Икигай** (по нему помогут как участнику нашего потока)
- Страна: **Нидерланды**
- ОС: **Ubuntu 24.04 LTS**
- Конфигурация: **2 vCPU / 4 GB RAM / 50 GB SSD**

> ⚠️ Кодовое слово **«Икигай»** — для FoxCloud. Не путай с кодовым словом урока **«НОВОСЕЛЬЕ»** (его пишешь Claude, чтобы поднять план урока).

## Что получить

Хостер пришлёт (письмом или в личном кабинете):
- **IP-адрес сервера**;
- **пароль root**.

## 🔐 Сразу: пароль — в менеджер паролей, один вход через VNC

1. **Сохрани пароль root в менеджер паролей** (Связка ключей / «Пароли» на Mac, Bitwarden, 1Password — любой, которым пользуешься). Не в заметки и не в Telegram «самому себе».
2. **Один раз войди на сервер через VNC-консоль хостера.** Это окно с чёрным экраном прямо в личном кабинете, у сервера (кнопка обычно называется «VNC» или «Консоль»; не находишь — спроси поддержку). Логин `root`, пароль из менеджера паролей.

Зачем: VNC — твой **аварийный вход**. Он работает, даже когда вход по сети закрыт. Если что-то пойдёт не так с ключами или файрволом, через VNC всё чинится. Проверить его нужно заранее, а не в момент паники. Шаг `lockdown` без проверенного VNC делать нельзя.

✅ **Получилось, если** в VNC-консоли после ввода пароля видна строка вида `root@…:~#`, а пароль лежит в менеджере паролей.

> 💡 В VNC пароль при вводе не отображается — ни точек, ни звёздочек. Это нормально: печатай и нажми Enter.

## 🔑 Файл доступа — данные сервера без чата

IP и пароль **никуда не отправляй**: ни в чат Claude, ни в Telegram, ни в открытую заметку. Открой Claude Code и вставь этот промпт целиком — агент создаст защищённый файл и откроет его тебе:

```text
Хостер прислал мне данные сервера. Передаю их тебе БЕЗ чата — через «Файл доступа».
Сделай строго так:

1. Создай Файл доступа:
   - Mac: ~/.config/brain/server_access (папке права 700, файлу 600);
   - Windows: %USERPROFILE%\.config\brain\server_access.
   Если файл уже есть — НЕ перезаписывай: переходи сразу к проверке (шаг 4).
   Если есть файл по старому пути (%USERPROFILE%\.secrets\brain\server_access.txt)
   или со старыми ключами IP / LOGIN / PORT / CLAUDE_TOKEN — скажи мне, перенеси
   значения в новые ключи ниже, строку CLAUDE_TOKEN не переноси (токен подписки больше
   в файле не храним), а старый файл удали только после моего «да».
2. Запиши в файл ровно такой шаблон. Пустые поля оставь ПУСТЫМИ, примеров не вписывай:
   # Файл доступа к твоему серверу. НИКОМУ не пересылай.
   # Вставь значения СРАЗУ ПОСЛЕ знака «=».
   # SERVER_IP — четыре числа через точку из письма хостера.
   # PASSWORD — пароль root, целиком и как есть (любые символы — нормально).
   #   Нужен только до шага lockdown, потом строку удалим.
   # BOT_TOKEN — от @BotFather, USER_ID — твоё число от @userinfobot (модуль 03A).
   #   Если бота ещё нет — оставь пустыми, заполнишь позже.
   # Заполнил? Сохрани (Cmd+S / Ctrl+S) и напиши в чат: «готово».
   SERVER_IP=
   SERVER_USER=root
   SERVER_PORT=22
   PASSWORD=
   BOT_TOKEN=
   USER_ID=
3. Открой файл мне на экран (в VS Code: `code <путь-к-файлу>`; не выходит — напиши путь
   и попроси открыть самому) и одной фразой скажи, что куда вписать. Дальше ЖДИ «готово».
4. Когда я напишу «готово» — прочитай файл и ПРОВЕРЬ значения.
   Читай только строки КЛЮЧ=значение; строки на «#» — комментарии; значение — всё после
   ПЕРВОГО «=» (в пароле может быть «=»); пробелы по краям отбрасывай.
   - SERVER_IP: четыре числа 0–255 через точку (или имя сервера от хостера);
     НЕ 127.0.0.1, НЕ 0.0.0.0, НЕ 1.2.3.4; не в угловых скобках.
   - SERVER_USER: одно слово (сейчас root). SERVER_PORT: число (обычно 22).
   - PASSWORD: не пустой. Отвергай ТОЛЬКО если значение целиком в угловых скобках
     или равно «пароль» / «password» / «пример». Любые другие символы — нормально.
   - BOT_TOKEN и USER_ID могут быть пустыми. Если заполнены: USER_ID — только цифры;
     BOT_TOKEN — число, двоеточие и длинный хвост.
   Что-то не так — открой файл снова, скажи КОНКРЕТНО какую строку поправить, жди «готово».
5. Пароль и токен НИКОГДА не выводи в чат — ни целиком, ни частично — и не подставляй
   их в команды (текст команд виден в чате). IP показывать можно.
6. Проверь делом: запусти шаг `brain-link detect` (скилл brain-link; если его ещё нет —
   скажи, что поставим на уроке) и перескажи итог простыми словами.
   С этого момента данные сервера у меня не спрашивай — бери из Файла доступа.
```

✅ **Получилось, если** Файл доступа открыт в VS Code, в нём вписаны `SERVER_IP` и `PASSWORD`, агент написал «значения прошли проверку», а пароль ни разу не появился в чате. Если `brain-link` уже стоит — `detect` назвал твою систему, нашёл Файл доступа и увидел сервер.

> 🔐 **Почему пароль временно лежит в файле.** На шаге `keys` brain-link покажет одну команду — ты введёшь её в терминал сам и один раз наберёшь пароль root. Дальше вход идёт по ключу, а после `lockdown` вход по паролю закрывается совсем и строку `PASSWORD` можно удалить. Пароль останется в менеджере паролей — для VNC.

## Definition of done (пре-ворк)

- сервер NL, Ubuntu 24.04, 2/4/50 — на руках;
- пароль root — в менеджере паролей, вход через VNC проверен;
- Файл доступа заполнен (`SERVER_IP`, `PASSWORD`; бот — по модулю 03A);
- подписка Claude активна;
- на Windows: в PowerShell команда `ssh -V` печатает версию (а не «не найдено»).

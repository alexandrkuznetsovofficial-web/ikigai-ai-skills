# 🖥 Пре-ворк — Заказать VPS (до урока!)

> Делай **за 2–4 дня до урока** — поддержке хостера нужен запас. К субботнему уроку сервер должен быть уже на руках.

## Самый простой путь (для нетехнического) — тикет в FoxCloud
Не регистрируйся сам через формы (в Потоке 1 на этом застревали). Напиши в поддержку **FoxCloud** (foxcloud.net) — тебе подберут и поднимут сервер живые люди.

**В заявке укажи:**
- Кодовое слово: **Икигай** (по нему помогут как участнику нашего потока)
- Страна: **Нидерланды**
- ОС: **Ubuntu 24.04 LTS**
- Конфигурация: **2 vCPU / 4 GB RAM / 50 GB SSD**

> ⚠️ Кодовое слово **«Икигай»** — это для FoxCloud. Не путать с кодовым словом урока **«НОВОСЕЛЬЕ»** (его пишешь Claude, чтобы поднять этот план).

## Что получить и сохранить
На выходе у тебя должно быть:
- **IP-адрес сервера**
- **root-пароль**

Сохрани их безопасно (НЕ в заметку с паролями в открытую, НЕ в чат). На уроке агент положит их в `~/.config/brain/server_pw` с правами 600.

## Definition of done (Стадия 1)
На руках: IP + root-пароль, вход проверен (агент на уроке выполнит `ssh root@<IP>` → `OK`).

→ Когда сервер на руках — переходи к `02_ПЕРЕЕЗД_МОЗГА_И_БОТ_24-7.md`.

# Выпускной пак v2: чекап и достройка второго мозга

> Для выпускников AI-Потока. kit 2.0. Продолжение аудит-пака, который получали выпускники прошлых потоков.

## Зачем

За поток вы собрали второй мозг. Пак отвечает на два вопроса:

1. **Насколько ваша система дотягивает до эталона.** В эталоне 23 точки: память и фокус, проекты отдельно от ядра, бэкап без личного, цифровой сад, граф
   связей, правило двойной ошибки, журнал обещаний, сжатие недели, брифинг, который не пропадает,
   когда компьютер засыпает.
2. **Как достроить то, чего не хватает,** ничего не сломав. Достройка только добавляет: делает
   снимок, показывает план и ждёт вашего «да».

Итог — слайд «было → стало» для выпускной презентации.

**Как считается.** Счёт идёт «X из N применимых». Часть точек про бота и сервер: точки 1–8, 10 и 11
меряют Telegram-бота, точка 12 — сторожей на расписании (обычно на сервере). Нет у вас бота или
сервера — такие точки помечаются **«не применимо»** и в N не входят. «Не применимо» — не провал и не
минус на слайде: «14 из 14 применимых» — честный полный результат. Точки 13–23 (устройство памяти)
применимы у всех; точка 23 «расписание переживает сон» достижима и без бота — брифинг может приходить
файлом или уведомлением (`SETUP_MORNING_BRIEF.md`, вариант без Telegram).

## Шаг 1. Чекап «до»

**1а. Быстрый скрипт.** Распакуйте архив в «Загрузки». Скрипт ничего не устанавливает и не меняет,
только смотрит.

| Mac | Windows |
|---|---|
| Откройте «Терминал» (Cmd+Пробел → «Терминал» → Enter) и вставьте одной строкой: | Нажмите «Пуск» → наберите «PowerShell» → откройте и вставьте одной строкой: |
| `cd ~/Downloads/AI_Potok_Graduation_Pack_v2/novoselie-server-kit/audit && bash audit.sh` | `cd $HOME\Downloads\AI_Potok_Graduation_Pack_v2\novoselie-server-kit\audit ; powershell -ExecutionPolicy Bypass -File .\audit.ps1` |

Если распаковали не в «Загрузки», подставьте свой путь.

Скрипт сам находит папку второго мозга по профилю компьютера, поэтому запускается из папки пака.

**Признак, что шаг сделан:** на экране список 🟢 / 🟡 / 🔴, а рядом со скриптом появился файл
`audit_report.md`. По желанию переименуйте его в `audit_report_before.md` — **это для себя**, чтобы
следующий запуск не перезаписал отчёт. Слайд «было → стало» строится не из этого файла, а из отчётов
подробного аудита в `~/.claude/audit/` (шаг 1б).

**1б. Подробный аудит.** Откройте Claude Code в папке второго мозга и вставьте:

```
Из выпускного пака (папка AI_Potok_Graduation_Pack_v2 в Загрузках) поставь скиллы
в ~/.claude/skills/ (на Windows — %USERPROFILE%\.claude\skills\), каждый в свою папку:
- папками целиком: ikigai-preflight, second-brain-audit, memory-upgrade, memory-garden,
  weekly-distill, craft-to-skill, project-splitter;
- однофайловые — файл кладётся как SKILL.md в папку с именем скилла:
  graduation/ikigai-graduation.md → ikigai-graduation/SKILL.md,
  meeting-1/morning-brief.md → morning-brief/SKILL.md,
  meeting-2-3/orchestrator.md → orchestrator/SKILL.md.
Если такой скилл уже стоит — покажи разницу и спроси, заменять ли.
Агентов из папки agents/ поставь по инструкции agents/README.md.
Брифинг по расписанию поставь по SETUP_MORNING_BRIEF.md — если он у меня уже стоит, только проверь.
Потом скажи мне перезапустить VS Code.
```

После перезапуска скажите: **«выпускной чекап»**. Скилл пройдёт 23 точки, покажет таблицу
«есть / частично / нет / не применимо», посчитает «X из N применимых» и сам сохранит её в
`~/.claude/audit/` с пометкой «до». Это вне папки
памяти, так что ни в облако, ни на сервер она не уедет. Потом скилл покажет план и остановится.

## Шаг 2. Достройка

Посмотрите план и скажите **«делай»** (или **«обнови мой второй мозг»**, если запускаете
достройку отдельно). Запустится `memory-upgrade`:

1. **Снимок** — копия системы до любых изменений.
2. **План** — что добавить и куда: стадии сада у заметок, журнал обещаний, список проектов,
   правило двойной ошибки в `CLAUDE.md`, расписание брифинга вместо cron.
3. 🛑 **Стоп** — ничего не меняется, пока вы не скажете «да».
4. **Применение** — только добавляет. Ваши файлы, ссылки и правила не удаляются и не переписываются.
5. **Повторный аудит** — сразу видно, что стало зелёным.

Повторный запуск безопасен: если всё уже на месте, скилл скажет «изменений нет».

Проекты со сроками скилл заполняет только черновиком. Сроки впишите сами: это ваши решения.

## Шаг 3. Чекап «после» и слайд «было → стало»

1. По желанию снова запустите скрипт из шага 1а (переименовать отчёт в `audit_report_after.md` —
   опять же для себя).
2. Скажите «выпускной чекап, прогон после». Скилл проверит по тому же эталону, сохранит отчёт
   в `~/.claude/audit/` рядом с первым и выдаст итог: «было X из N применимых → стало Y из N применимых».
3. Скажите «сделай мою выпускную презентацию». Слайд «было → стало» скилл соберёт из двух отчётов в
   `~/.claude/audit/`. Успели только прогон «до» — слайд всё равно будет: «Старт: X из N применимых»
   и следующий шаг.

## Если красное

Красное значит «ещё не достроено», ничего не сломалось. Чинить в таком порядке:

| Что красное | Что делать |
|---|---|
| Безопасность: пароли или ключи в памяти, память уходит в GitHub, личное в облаке | **Первым.** Скажите «позови агента secops, пусть проверит мою папку второго мозга» (агента из `agents/`, не скилл secops из серверного кита). Затем `meeting-2-3/auto-commit-backup.md`: память остаётся на компьютере, в облако уходят только скиллы и код |
| Точки 18–23: сад, граф, правило двойной ошибки, обещания, сжатие недели, расписание | «обнови мой второй мозг» (шаг 2) |
| Точки 1–8, 10–12 про бота и сервер | бота или сервера нет — это «не применимо», не красное. Захотите — модуль «Новоселье» |
| Точка 17: специалисты упоминаются, а не вызываются | `meeting-2-3/orchestrator.md`: соберёт `TEAM.md` и по желанию поставит хук-диспетчер |
| Точка 13: проекты перемешаны с ядром | скажите «разнеси проекты» — скилл `project-splitter` |
| Сжатие недели: нет свежего файла в `memory/distill/` | в пятницу скажите «сверни неделю» |
| Брифинг стоит в cron и пропускает утра | `SETUP_MORNING_BRIEF.md`: на Mac — launchd, на Windows — Планировщик заданий |
| «Сервера пока нет» | это модуль «Новоселье» — переезд мозга на сервер: папка `novoselie-server-kit/`, начните с её README |
| Скрипт не запускается на Windows | проверьте, что вставили строку целиком, вместе с `-ExecutionPolicy Bypass` |
| Непонятно, что значит пункт | скопируйте строку из отчёта в Claude Code и спросите «что это значит и как починить» |

Остались вопросы — напишите в чат своего потока и приложите строку отчёта, а не весь файл.

## Безопасность

- 🔒 **Пароли, коды подтверждения и коды восстановления не присылайте никому**: ни Claude, ни
  агентам, ни куратору, ни в чат потока. Ни один шаг этого пака их не просит. Если кто-то просит —
  это ошибка, остановитесь.
- Если раньше уже присылали пароль от GitHub или коды восстановления: выпустите новые коды,
  смените пароль, включите двухфакторную защиту.
- Скрипт чекапа только читает и не выводит секреты на экран.
- Память (`memory/`, особенно `memory/personal/`) в GitHub не отправляется. GitHub — только для
  скиллов и кода.
- Отчёты чекапа могут содержать имена ваших файлов. Делитесь строкой с вопросом, а не всем отчётом.

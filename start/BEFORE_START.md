# Памятка: что сделать до встречи · kit 2.3

Четыре вещи, которые делаешь ты сама — заранее, за 2–4 дня. Всё остальное на встрече сделает Claude.

## 1. Сервер (VPS)

- Хостер — любой, у кого есть сервер **вне России** на **Ubuntu 24.04 LTS**: FoxCloud, Aeza и другие.
  Нужно: **2 vCPU / 4 GB RAM / 50 GB SSD**, страна — например, Нидерланды.
- Проще всего — написать в **чат поддержки** хостера: сервер подберут и поднимут живые люди. Оператора иногда
  приходится подождать — это нормально. У FoxCloud назови кодовое слово «Икигай».
- Оплата — по ссылке из письма или через СБП, около **600–660 ₽ в месяц**. При оплате выключи VPN.
- Хостер пришлёт **IP-адрес** и **пароль root** (письмом или в личном кабинете). Сразу сохрани пароль в менеджер
  паролей. Пароль от **личного кабинета** хостера никому не нужен — ни Claude, ни нам.
- Все доступы потом живут в **одном** файле, который откроет Claude. Отдельные txt с паролями заводить не нужно.

## 2. Бот в Telegram и твой id

- Бот: в Telegram открой **@BotFather** → `/newbot` → придумай имя и адрес бота (на конце `bot`). BotFather
  пришлёт **токен** — длинную строку с двоеточием. Сохрани рядом с паролем сервера.
- Твой id: открой **@userinfobot** → он пришлёт число **Id**. Это твой адрес для бота: отвечать он будет только тебе.
- Уже есть свой бот на сервере (ставили раньше)? Новый не нужен — Claude перенесёт старый.

## 3. Подписка Claude

Нужна **Claude Pro** или **Max**. Бот на сервере отвечает моделью Opus (самая сильная); на Pro лимит у неё
кончается быстрее — тогда в боте есть `/fast` (быстрый ответ моделью Sonnet).

## 4. Claude Code: режим Auto

- В VS Code внизу окна чата Claude, рядом с полем ввода, должен стоять режим **Auto**.
- Если Claude скажет, что какое-то действие отклонено, и попросит повторить его — повторяй, **только если команда
  начинается с `brain_link.py`, это пробник или копирование скиллов кита** (Claude покажет точную команду и зачем).
  Любое другое — не повторяй, напиши «далее».
- Остановила Claude кнопкой «стоп» или он долго молчал — просто напиши «далее». Новая сессия — «продолжи связку по журналу».

Текст, который нужно вставить в Claude Code на встрече, — `start/PASTE_TEXT.md`.

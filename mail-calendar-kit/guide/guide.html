1. Что вы получите

Восемь задач, из которых на старте выбираются две-четыре. Остальные добавляются потом.

Главное отличие от «спросить у ИИ». Модель перестаёт рассуждать о вашем дне в общем виде и начинает смотреть в ваш календарь и вашу почту. Ответ становится проверяемым.

2. Как это устроено

Три вещи, и больше ничего:

ваш почтовый сервис пароль приложения ваш второй мозг (Яндекс, Gmail, ...) ──────────────────────────▶ Claude Code · личный бот почта IMAP/SMTP отдельный, отзываемый два небольших скрипта календарь CalDAV не равен паролю входа читают и пишут по запросу

IMAP и SMTP — то, как программы читают и отправляют почту, CalDAV — то же самое для календаря. Дальше эти слова не понадобятся.

Пароль приложения — отдельный пароль для одной программы. Его можно отозвать, не меняя основной пароль, и войти с ним в аккаунт через браузер нельзя. Именно поэтому им безопасно пользоваться в системе, которая работает круглосуточно.

Почему скрипты, а не «подключение одной кнопкой»

Готовые коннекторы к почте существуют, но у них два ограничения, которые ломают именно наш случай: часть из них подключается только через сайт и не работает на сервере, а часть не видна программе, когда та запускается сама, без человека. Два небольших скрипта работают одинаково на компьютере и на сервере, проверяются одной командой и не зависят ни от чьих планов подписки.

Что в пак не входит. Outlook и Microsoft 365: вход сторонних программ по паролю там отключён, нужен отдельный механизм авторизации. Это другая история и другой вечер.

3. Что нужно до старта

  • Claude Code в VS Code, вы уже в нём работаете
  • Собранный второй мозг: папка с памятью и файлом правил
  • Доступ к настройкам своего почтового ящика (логин и пароль от аккаунта)
  • Вечер спокойного времени. Почта поднимется сразу, календарь Яндекса дозреет через 2–3 часа
  • Не обязательно: личный телеграм-бот и сервер. Без них всё работает на компьютере
Про Яндекс-календарь заранее. Пароль приложения для календаря начинает действовать через 2–3 часа после создания. Почта заработает сразу, календарь — позже. Это не поломка. Если планируете сделать всё за один заход — создайте пароль календаря первым делом, а потом занимайтесь почтой.

4. Старт: один текст в чат

Откройте Claude Code в папке своего второго мозга и вставьте одним куском текст из файла copy_paste_for_student.md. Первым делом Claude сохранит этот текст себе на диск — поэтому маршрут переживёт закрытие окна.

Дальше он скачает пак, положит скилл в общую папку скиллов и начнёт вести вас по шагам.

# это он выполнит сам, вам вводить ничего не нужно
git clone https://github.com/alexandrkuznetsovofficial-web/ikigai-ai-skills.git ~/ikigai-kit
cp -r ~/ikigai-kit/mail-calendar-kit ~/.claude/skills/
Правило вечера. Вы не открываете терминал. Все команды выполняет Claude. Руками вы делаете ровно два вида действий: кликаете в браузере на сайте своей почты и вставляете пароль в файл, который он вам откроет. Если вас просят «выполнить команду» — напомните про это правило.

5. Аудит: что он спросит и покажет

Сначала он смотрит, что у вас уже есть, и показывает таблицу: система, Python, версия Claude, редактор, есть ли личный бот и какой, доступен ли сервер. Ничего не предполагает — только замеряет.

Потом четыре вопроса, по одному за раз:

  1. Какая у вас почта: Яндекс, Gmail, Mail.ru, iCloud, другая
  2. Какой календарь: тот же сервис, Google Calendar, нет календаря
  3. Где нужен результат: только на компьютере или ещё и в личном боте
  4. Пользуетесь ли Notion

После этого он покажет, что даст интеграция именно у вашего сервиса и чего не даст, и предложит выбрать 2–4 задачи из восьми. Выбранное станет чек-листом приёмки: в конце вечера по каждому пункту должна пройти проверка.

6. Яндекс

Нужны два разных пароля приложения: один для почты, другой для календаря. Это не дублирование — у Яндекса они разных типов.

Шаг 1. Пароли

1Яндекс ID → Безопасность → «Доступ к вашим данным» → Пароли приложений.

2Создать пароль типа «Почта», назвать понятно («второй мозг»).

3Создать второй пароль типа «Календарь».

Пароль показывается один раз. Не закрывайте окно, пока не вставили его в файл. Яндекс печатает его группами через пробел — пробелы нужно убрать.

Шаг 2. Включить IMAP

Почта → Настройки → Почтовые программы → включить доступ по протоколу IMAP. Без этого верный пароль всё равно даст ошибку.

Шаг 3. Вставить в файл

Claude откроет у вас в редакторе файл доступов и подождёт. Вы вставляете пароль почты в строку MAIL_PASSWORD, пароль календаря — в CALDAV_PASSWORD, сохраняете и пишете «готово».

Почему в файл, а не в чат. Всё, что попадает в переписку, остаётся в истории разговора. Пароль туда не должен попадать. Если случайно отправили — отзовите его в том же разделе и создайте новый, это занимает минуту.

Шаг 4. Проверка

Claude запускает проверку входа. Ответ «почта подключена, во Входящих N писем» — готово. Ошибка на календаре сразу после создания пароля — ждём 2–3 часа.

Календарь Gmail подключается иначе. Для почты Google пароль приложения работает, а для календаря — нет: там нужен вход через браузер. Это следующий раздел.

8. Google Calendar

Здесь дольше всего — примерно двадцать минут, и почти всё время занимает кликанье в консоли Google. Зато потом к этому не возвращаются: доступ не протухает.

1console.cloud.google.com → создать проект → включить Google Calendar API.

2APIs & Services → Credentials → Create credentials → OAuth client ID → тип Desktop app → скачать файл JSON.

3OAuth consent screen → Publish app.

4Claude кладёт скачанный файл куда нужно и запускает вход — откроется браузер, вы подтверждаете доступ.

Пункт 3 пропускать нельзя. Пока приложение остаётся в статусе Testing, доступ протухает каждые 7 дней, и бот будет замолкать раз в неделю без внятной причины. Одна кнопка сейчас — и бот не замолкает каждую неделю.

Официальная инструкция Google с картинками: developers.google.com/workspace/calendar/api/quickstart/python. Интерфейс консоли меняется, последовательность разделов — нет.

9. Notion, по желанию

Два пути, выбор зависит от того, где нужен результат.

  • На компьютере — готовый коннектор, подключается одной командой и входом через браузер.
  • В боте на сервере — постоянный ключ интеграции. Главный шаг, который все пропускают: интеграции нужно дать доступ к страницам вручную («•••» → Connections → Add connections). Сама по себе она не видит ничего.

Подробности — notion.md.

В Notion не выгружаем личное: здоровье, семью, финансы. Это общий рабочий контур, доступ к нему нередко есть не только у вас.

10. Подключение к личному боту

Нужно, только если хотите спрашивать с телефона. На компьютере всё работает и без этого шага.

Какой у вас ботЧто происходит
Бот-мост на Claude Code Код не трогаем вообще. Скилл и файл доступов копируются на сервер — бот получает инструменты сам, потому что умеет запускать команды
Учебный бот на ключе API Claude патчит его одним скриптом: сначала показывает, что изменится, потом применяет. Скрипт сам делает копию файла с датой и проверяет, что бот не сломался; если сломался — возвращает копию обратно
Бота нет Шаг пропускается. Вернётесь после урока про бота, пак трогать не придётся

Проверка одна: вы пишете боту «что у меня сегодня в календаре» и видите реальные события.

11. Приёмка и безопасность

В конце Claude проходит ваш чек-лист из двух-четырёх задач, каждую — командой, и ставит ✅ или ❌ с выводом. Не «кажется, работает», а показанный результат.

Если письмо не находится — попросите поискать по всем папкам. Это самая частая причина «поиск не работает»: правила сортировки уносят письма из Входящих, а ищут их только там.

Три правила, которые остаются с вами

  1. Отправка выключена по умолчанию. Пока вы не включите её осознанно, письма не уходят и приглашения не рассылаются. Включается одной строкой в файле доступов.
  2. Подтверждение перед каждой отправкой. Даже при включённой отправке письмо и встреча сначала показываются вам. «Да» — ушло, «нет» — отменено. Это встроено в инструмент, а не в вежливость модели.
  3. Адрес участника никогда не угадывается. Нет адреса — Claude останавливается и спрашивает. Правдоподобный выдуманный адрес хуже отсутствующего: приглашение уходит в никуда, а вы уверены, что человек его получил.

Гигиена доступов

  • Файл доступов лежит вне папки второго мозга и не должен попасть в общий репозиторий.
  • На каждый сервис — свой пароль приложения. Тогда отзыв одного не роняет остальные.
  • Пароль приложения отзывается там же, где создавался, и это не влияет на вход в аккаунт.

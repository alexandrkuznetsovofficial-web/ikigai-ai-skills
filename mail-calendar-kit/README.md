# Пак «Второй мозг ↔ почта и календарь»

Подключает почту и календарь человека к его второму мозгу и личному Telegram-боту.
После установки можно спрашивать: «что у меня завтра», «найди письмо от Иванова», «когда
свободное окно на этой неделе», «поставь встречу с Ириной во вторник в три», «перенеси её
на четверг», «отмени планёрку».

**Терминал открывать не нужно.** Все команды выполняет Claude Code; от человека — выбрать
вариант на развилке и вставить пароль приложения в файл, который Claude сам откроет.

## Как запустить

**Из этого репозитория:** скопируй папку `mail-calendar-kit` в `~/.claude/skills/mail-calendar-kit`
(на Windows — `%USERPROFILE%\.claude\skills\mail-calendar-kit`), затем вставь в чат Claude Code
текст из `copy_paste_for_student.md`.

**Из архива в кабинете Академии:** распакуй архив и вставь текст из `copy_paste_if_downloaded_zip.md`.

## Статус, честно

Полностью пройден руками один путь: Яндекс-почта и Яндекс-календарь на Mac. Чтение календаря
по ссылке iCal проверено на сервере Google. Gmail, iCloud, полный доступ к Google Calendar,
Windows и подключение к боту на сервере расписаны по официальным справкам, но живьём их пока
никто не проходил — пак предупреждает об этом сам и идёт медленнее.

## Безопасность

Пароли приложений, а не основные. Отправка писем, приглашения и удаление встреч по умолчанию
выключены предохранителем: сначала превью, действие только после «да» владельца. Адрес участника
встречи берётся исключительно из слов владельца и никогда не придумывается.

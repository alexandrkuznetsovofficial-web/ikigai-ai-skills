# Notion — необязательный шаг

Notion подключается иначе, чем почта: там не пароль приложения, а либо вход через браузер,
либо постоянный ключ доступа. Два пути, выбор зависит от того, где нужен результат.

---

## Путь 1. На компьютере, через готовый коннектор

Подходит, если Notion нужен в Claude Code, а не в боте на сервере.

```
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

Затем человек набирает в Claude Code `/mcp` → выбирает `notion` → откроется браузер → подтверждает доступ.

Это **единственное место во всём паке, где он что-то набирает сам**. Скажи об этом прямо: `/mcp` —
не команда терминала, а команда самого Claude Code, и вводится она в том же окне чата.

Если браузер ругается на адрес возврата (известная ошибка `Invalid redirect_uri`), добавь порт:

```
claude mcp add --transport http --callback-port 8080 notion https://mcp.notion.com/mcp
```

**Ограничение:** такой вход требует живого браузера и человека. На сервере, где бот работает сам
по себе, этот путь не годится — Notion пока не поддерживает вход без участия человека.

**Проверка:** `/mcp` показывает `notion` подключённым, и Claude находит страницу по названию.

---

## Путь 2. На сервере, через ключ интеграции

Подходит для бота и любых запусков без человека. Ключ постоянный, ничего не протухает.

1. Открыть `notion.so/profile/integrations` (нужны права владельца пространства) → **New integration**
   → название, рабочее пространство, тип **Internal**.
2. Скопировать **Internal Integration Secret**.
3. Вписать его в файл доступов строкой `NOTION_TOKEN=` (ключ вставляется в файл, не в чат).
4. **Дать интеграции доступ к страницам.** Это главный шаг, о котором забывают: сама по себе
   интеграция не видит ничего. На нужной странице или базе: «•••» → **Connections** → **Add connections**
   → выбрать свою интеграцию. Доступ наследуется вложенными страницами.

**Проверка:** страница, к которой доступ выдан, читается; страница без доступа — нет.
Второе не ошибка, а правильное поведение.

---

## Что с этим делать дальше

Полезнее всего не «подключить Notion», а решить одну задачу:

- итог разговора с ботом падает страницей в базу заметок;
- задачи из письма превращаются в строки базы задач;
- перед встречей бот достаёт из Notion страницу по этому человеку или проекту.

Задачу выбирает человек, дальше Claude Code пишет ему небольшой скрипт под его базу: у каждого
своя структура полей, универсального решения здесь не бывает.

## Границы

- Не выгружать в Notion личное: здоровье, семейное, финансы. Notion — общий рабочий контур,
  и доступ к нему часто есть не только у владельца.
- Ключ интеграции даёт доступ ко всем страницам, которыми с ней поделились. Отзывается там же,
  где создавался.

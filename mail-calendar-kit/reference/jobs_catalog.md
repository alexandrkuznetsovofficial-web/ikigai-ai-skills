# Что можно автоматизировать: восемь готовых задач

Он выбирает 2–4 пункта. Это и будет чек-лист приёмки: по каждому в конце должна пройти команда.

---

### 1. «Что у меня сегодня / завтра»

Расписание дня словами, без открывания календаря.

```
cal_cli.py today
cal_cli.py list --days 2
```
**Готово, когда:** список событий дня совпадает с тем, что он видит в своём календаре.

---

### 2. «Найди свободное окно»

Окна нужной длины в рабочие часы, без наложений на занятое.

```
cal_cli.py freeslots --days 7 --duration 60
cal_cli.py freeslots --days 14 --duration 30 --weekdays
```
Рабочие часы берутся из файла доступов (`WORK_HOUR_FROM`, `WORK_HOUR_TO`), по умолчанию 10:00–19:00.
`--lead-hours 3` — не предлагать ближайшие три часа.

**Готово, когда:** предложенные окна действительно свободны в его календаре.

---

### 3. «Поставь встречу» и пришли приглашение

```
cal_cli.py create --start 2026-09-15T15:00 --duration 60 --summary "Разбор проекта" \
    --location "https://…" --attendee ivanov@example.com --invite --confirm
```
Без `--confirm` показывается превью и ничего не создаётся. `--invite` отправляет участнику письмо
с файлом приглашения: CalDAV-серверы сами приглашения не рассылают, это делается отдельным письмом.

**Адрес участника берётся только из его слов.** Нет адреса — остановиться и спросить.

**Готово, когда:** событие появилось в календаре, участник получил письмо.

---

### 4. «Найди письмо от…»

```
mail_cli.py search --from ivanov --days 60
mail_cli.py search --subject "договор" --days 90 --all-folders
mail_cli.py read --uid 12345
```
Поиск возвращает заголовки с номером письма, а полный текст читается отдельной командой — так
переписка не забивает собой всю память разговора.

**`--all-folders` — главный ключ.** Письмо часто лежит не во «Входящих», а в папке, куда его
отнесли правила сортировки.

**Готово, когда:** нашлось конкретное письмо, которое он назвал.

---

### 5. «Что там в непрочитанных»

```
mail_cli.py unread --limit 15
```
Дальше модель группирует: что требует ответа, что можно прочитать позже, что рассылка.
Чтение не помечает письма прочитанными.

**Готово, когда:** сводка совпадает с тем, что он видит в ящике.

---

### 6. «Ответь на это письмо»

```
mail_cli.py send --to ivanov@example.com --subject "Re: договор" --body "…" --reply-uid 12345
# показывает превью, письмо не уходит
mail_cli.py send … --reply-uid 12345 --confirm
# уходит после «да»
```
Ответ подхватывает тему и связывается с исходным письмом, поэтому в ящике получателя он ложится
в ту же переписку.

Требует `MCK_SEND_ALLOWED=1` в файле доступов — предохранитель включается на приёмке осознанно.

**Готово, когда:** письмо себе дошло и нашлось поиском.

---

### 7. «Утренний брифинг»

Одно сообщение утром: события дня, свободные окна, важное из непрочитанного.

Собирается из трёх вызовов (`cal_cli.py today`, `cal_cli.py freeslots --days 1`,
`mail_cli.py unread`) и одного правила: что считать важным. Правило пишется в память второго мозга,
не в код — оно у каждого своё.

**Готово, когда:** брифинг приходит в бот и в нём нет мусора.

---

### 8. «Заметка в Notion»

Отправить итог разговора или список задач в базу Notion. См. `reference/notion.md`.

**Готово, когда:** страница появилась в нужной базе.

---

## Чего этот пак не делает

- **Массовые рассылки.** Одно письмо за вызов, каждое — после подтверждения. Для рассылок нужны
  другие инструменты и другие правила.
- **Автоматические ответы без человека.** Модель готовит текст, отправляет человек своим «да».
- **Перенос всей почты в память.** Письма читаются по запросу. Складывать ящик целиком во второй
  мозг вредно: он станет хуже находить нужное.
- **Удаление писем.** Ни одна команда пака не удаляет почту.

---

## 9. Перенести или отменить встречу голосом

«Перенеси встречу с Ириной на четверг в три», «отмени завтрашнюю планёрку».
Бот находит встречу по названию, показывает превью с названием и временем, и действует
только после «да». Проверка: встреча переехала, старой записи в календаре нет.
Повторяющиеся встречи не переносятся — про это пак говорит честно и отправляет в календарь.

# Слова эксплуатации

| Термин | Что означает |
|---|---|
| Главная копия | Место, где сведения считаются актуальными и редактируются |
| Синхронизация | Обмен изменениями; ошибку тоже может размножить |
| Резервная копия | Отдельная версия данных для восстановления |
| Snapshot / снимок | Состояние выбранных файлов на конкретный момент |
| Manifest | Список файлов архива с их контрольными суммами |
| SHA-256 | Отпечаток содержимого для проверки совпадения, а не шифрование |
| Staging | Отдельная временная папка для проверки восстановленных файлов |
| Retention | Выбранный срок хранения старых копий; здесь автоудаление выключено |
| Rollback / откат | Возврат выбранной предыдущей версии после проблемы |
| Timer / планировщик | Механизм реального запуска по времени, а не строчка в инструкции |
| Наблюдаемость | Возможность увидеть состояние, последний запуск и ошибку |
| Incident / инцидент | Сбой или раскрытие данных, требующее конкретного действия |

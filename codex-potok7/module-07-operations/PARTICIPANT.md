# Как подготовить страховку своего второго мозга

Модуль помогает понять, где главная копия, как вернуть ошибочно изменённый файл и что делать при обновлении. Сейчас подготовлены материалы без прогонов.

1. Открой свою папку в Codex, прикрепи START.md и отправь запрос подготовки. Команды вводить не требуется.
2. Вместе составьте карту: рабочая папка, отдельные снимки, резервная копия устройства, входящие сервера. Уточни, есть ли картинки, аудио и другие вложения: текстовый скрипт их не сохраняет.
3. Выбери, где будут лежать копии. Второй каталог на том же диске защищает от неверной правки, но не от потери компьютера. Облачное или платное хранилище подключается только по твоему выбору.
4. Когда решишь выполнять, попроси создать конкретный снимок. Для восстановления сначала выбирается архив и отдельная временная папка. Живые файлы автоматически не заменяются.
5. Расписание выбери отдельно. Затем потребуется убедиться, что оно реально создало новый архив. Пока этого не было, оно считается непроверенным.

Архивы этого скрипта не зашифрованы. Не отправляй их в общий чат и не публикуй. Секреты из конфигов аккаунтов в них не включаются; пароль, случайно записанный в заметке, не становится безопасным от формата ZIP.

Готовность позже доказывает реальное восстановление нужного результата. Сейчас статус модуля — подготовлен без запуска.

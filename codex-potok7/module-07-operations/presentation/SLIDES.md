## Слайд 2. Сначала понимаем, где главная копия

КАРТА ДАННЫХ

Рабочая папка — Здесь редактируется актуальная память.

Серверный inbox — Здесь могут ждать новые заметки.

Отдельный backup — Версии для возврата после ошибки.

**Ведущему:** Не считать сервер единственной страховкой. Спросить о медиа и вложениях; текстовый snapshot не сохраняет всё. Не читать все личные каталоги ради карты.

## Слайд 3. Синхронизация и копия решают разные задачи

ДВА ПОНЯТИЯ

Синхронизация: Переносит изменения; Может размножить ошибку; Нужны правила конфликтов.

Резервная копия: Сохраняет версию; Помогает вернуться назад; Нужно проверить восстановление.

**Ведущему:** Привести пример: ошибочно удалённая заметка может исчезнуть в двух синхронных местах. Отдельная предыдущая версия помогает её вернуть.

## Слайд 4. Текстовый snapshot имеет явный состав

ПОКРЫТИЕ

Входит — Правила, профиль, текстовая память и навыки.

Не входит — Медиа, базы, auth, токены и секретные каталоги.

Отдельно — Системное резервирование устройства.

**Ведущему:** Скрипт разрешает определённые текстовые суффиксы и бюджеты. Не заявлять «весь компьютер сохранён». При секретах в MD их формат не делает данные безопасными.

## Слайд 5. План предшествует реальному снимку

СОЗДАНИЕ

Текущий скрипт по умолчанию ничего не создаёт.

Выбрать — Источник и отдельное место

Посмотреть план — Без записи

Создать версию — По выбранному действию

**Ведущему:** В этой поставке даже dry-run не выполнялся. --apply необходим для реального действия. Участник команды не вводит, их выполняет агент по запросу.

## Слайд 6. Копия на том же диске не спасает от потери диска

МЕСТО ХРАНЕНИЯ

Локальная версия: Помогает при неверной правке; Быстро доступна; Теряется вместе с устройством.

Отдельная защита: Выбранный внешний носитель; Системный backup; Свои условия доступа.

**Ведущему:** Облачное/платное хранилище не подключать автоматически. ZIP скрипта не зашифрован. Права доступа и шифрование — разные механизмы.

## Слайд 7. Manifest описывает состав архива

ПРОВЕРКА СОДЕРЖИМОГО

Manifest — Список файлов версии.

SHA-256 — Проверка совпадения содержимого.

Ограничение — Не шифрование и не доказательство автора.

**Ведущему:** Объяснить контрольную сумму простым примером отпечатка. При архиве неизвестного происхождения одной контрольной суммы из того же архива недостаточно для доверия.

## Слайд 8. Сначала staging, потом выбранная замена

ВОССТАНОВЛЕНИЕ

Живая память не перезаписывается скриптом.

Выбрать архив — Нужная дата и задача

Распаковать отдельно — Новая временная папка

Сравнить — Что действительно вернуть

**Ведущему:** Staging — временное место для проверки. Перед любой живой заменой сохранить текущую версию и приостановить свою запись. Не откатывать весь мозг из-за одного файла.

## Слайд 9. Файл задания ещё не означает автозапуск

РАСПИСАНИЕ

Mac — LaunchAgent с фактическими путями.

Windows — Task Scheduler и пропущенный запуск.

Linux — User systemd timer с Persistent.

**Ведущему:** Сначала выбранное ручное действие, затем отдельная установка расписания. Шаблоны не проверены на целевых ОС. До появления нового архива после времени — scheduled_unverified.

## Слайд 10. Старые копии не удаляются молча

ХРАНЕНИЕ ВЕРСИЙ

Срок хранения — Выбирает владелец с учётом места.

Автоудаление — В этой версии отсутствует.

Свободный диск — Проверяется отдельным обзором.

**Ведущему:** Retention — срок хранения. Не добавлять очистку на своё усмотрение. При заполненном диске нужна понятная ошибка, а не ложный успех backup.

## Слайд 11. Новую версию сопровождает путь назад

ОБНОВЛЕНИЯ

Личные правки ученика сохраняются при обновлении.

Снимок — Сохранить текущие файлы

Diff — Показать конкретные изменения

Rollback — Вернуть выбранную версию

**Ведущему:** Не копировать новый AGENTS целиком поверх старого. Обновления Codex и навыка могут иметь разную совместимость. При отложенных проверках — updated_unverified.

## Слайд 12. Ошибка должна подсказывать следующий шаг

ИНЦИДЕНТЫ

Бот не отвечает — Служба, сеть, авторизация или лимит.

Нет нового архива — Диск, права или расписание.

Раскрыт секрет — Отозвать и перевыпустить значение.

**Ведущему:** Логи без паролей, токенов и содержимого личных запросов. Не переключать на платный API автоматически. Удаление сообщения с секретом не отзывает значение.

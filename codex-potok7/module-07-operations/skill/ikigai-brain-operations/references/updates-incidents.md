# Обновления, наблюдаемость и инциденты

## Перед обновлением

Зафиксировать текущую версию Codex/навыка/службы и источник новой версии. Прочитать примечания о совместимости. Создать снимок выбранных текстовых файлов. Сравнить изменения, убрать из плана не относящиеся к задаче. Не перезаписывать изменённые учеником инструкции новым шаблоном. Новый навык сначала сохранить в отдельный release-каталог; после выбранного переключения оставить старую копию для отката. Установку неподписанного/неизвестного скрипта из случайного источника не считать нормальным обновлением.

## Что наблюдать вручную

| Сигнал | Что означает | Следующее действие |
|---|---|---|
| Нет нового архива | Расписание/права/диск могли не сработать | Проверить конкретное задание и свободное место |
| Бот не отвечает | Служба, сеть, авторизация или лимит | Проверить статус без вывода токенов; не повторять модельный запрос бесконечно |
| Есть серверный inbox, но его нет на компьютере | Входящие ещё не импортированы | Staging-импорт с дедупликацией update_id |
| Слишком много постоянного текста | Контекст тратится на несвязанные правила | Короткий корневой инструктаж и выборочное чтение |
| Конфликт версий | Меняли два источника | Сохранить обе версии; выбрать главный источник с человеком |

Расходы: отдельно стоимость сервера, подписки/выбранного API и сторонних сервисов. Точный остаток подписки неизвестен без фактических показаний интерфейса. Ошибка лимита = пауза и понятный статус, не автоматическое переключение на платный API.

## Откат

Остановить только свою службу/задание записи; сохранить новые входящие. Вернуть выбранную предыдущую версию кода или контекста из отдельного release/snapshot. Не откатывать весь brain из-за одного ошибочного файла. После отката нужны выбранные проверки; без них статус rolled_back_unverified. Отозванные токены и авторизацию не восстанавливать из старой копии — выдать заново официально.

## Секрет попал в чат или публичный файл

Сначала отозвать/перевыпустить конкретный секрет; удаление сообщения или файла само по себе не делает старое значение безопасным. Не печатать его в отчёт. Сохранить только тип, место и действия. До изменения публичной истории Git или удаления ресурсов показать конкретный план владельцу. Учебный пакет не даёт разрешения удалять чужой репозиторий или сервер.

## Выход из сервиса

Отключить собственные задачи, экспортировать выбранные результаты, сохранить подтверждённый backup, отозвать доступы и только после выбора владельца прекращать платные ресурсы. Сервер не удалять до проверки, что inbox и нужные материалы не остались там в единственном экземпляре.

# Расписание — отдельное выбранное действие

Все шаблоны непроверены на целевых ОС. Их наличие не означает работающую автоматизацию. Сначала выбранное ручное действие, затем отдельная установка расписания по запросу ученика. Момент запуска, часовой пояс, путь Python, установленного навыка, мозга и backup заполняются реальными абсолютными путями. Не оставлять ABS_*.

| ОС | Механизм | Что учитывать |
|---|---|---|
| Mac | LaunchAgent из assets/ikigai-backup.plist | Права пользователя, доступ к папкам/диску, сон и последний успешный запуск |
| Windows | Планировщик задач через GUI | Создать задачу от пользователя, StartWhenAvailable; абсолютный путь python.exe, аргументы snapshot, правильная рабочая папка |
| Linux | User systemd service+timer из assets | Persistent=true, доступность внешнего диска; не запускать от root |

Для Windows создаётся задача `Ikigai student brain backup` через интерфейс: действие «Запуск программы» — фактический путь Python; аргументы — путь установленного snapshots.py, snapshot, --source, --dest, --apply; параметры: запуск после пропущенного времени и выбранный календарь. Задачу не настраивать на «с максимальными правами» ради обхода доступа. Пароль учётной записи пользователь вводит только в системное окно.

Расписание делает новые снимки без удаления старых; свободное место контролирует человек/агент по отдельному обзору. После изменения пути диска или компьютера обновить задание. При отключённом диске отметить failed_backup и уведомить владельца доступным согласованным каналом; канал уведомления не появляется из текстовой инструкции.

Проверка после реальной настройки: выбранное время прошло, появился НОВЫЙ архив, его manifest читается, задания не дублируются. До этого статус scheduled_unverified. Отдельно проверить выбранное поведение после сна/пропуска времени. Сейчас эти проверки отложены.

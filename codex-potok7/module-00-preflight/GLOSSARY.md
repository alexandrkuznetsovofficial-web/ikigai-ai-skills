# Слова подготовки

| Слово | Объяснение | Пример |
|---|---|---|
| Клиент | Приложение или расширение, через которое ты работаешь | Приложение с режимом Codex или расширение редактора |
| Рабочая папка | Выбранное место для файлов системы | second-brain |
| Локально | На твоём компьютере | Файл лежит на диске; это не гарантия офлайн-обработки моделью |
| Разрешение | Какие действия приложению доступны | Читать файл или записывать в выбранную папку |
| Авторизация | Подтверждение твоего входа | Вход в официальном окне |
| Подписка / API | Разные способы доступа и расчёта использования | Вход ChatGPT и отдельно оплачиваемые API-вызовы |
| Профиль среды | Запись наблюдений о компьютере и доступе | ОС, текущая папка, возможность записи |

Ни одно слово не нужно учить заранее: ведущий объясняет его перед действием.

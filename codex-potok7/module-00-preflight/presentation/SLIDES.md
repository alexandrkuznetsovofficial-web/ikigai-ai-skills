# Модуль 0 · Сначала откроем твоё рабочее место · сценарий презентации

Александр Кузнецов и команда AI-Потока. Черновик 0.2 без функционального прогона, 2 ноября 2026.

Сценарий редактируется в `tools/build_presentation.py`; сборщик обновляет HTML и этот MD. Результат и последовательность этого модуля указаны в START.md. Экспорт слайдов не является прогоном установки или функциональности.

## Слайд 1. Сначала откроем твоё рабочее место

AI-ПОТОК 7 · ПОДГОТОВКА

Codex, собственный вход и отдельная папка.

Без прежнего Claude и без команд для ученика.

**Ведущему:** Черновик без живого прогона. До работающего клиента человек следует официальной инструкции, агент не может установить себя из неработающего чата.

## Слайд 2. Пустая папка — нормальное начало

ВХОДНАЯ ТОЧКА

У тебя ещё ничего нет — Подготовим клиент и доступ к файлам.

Есть старая система — Оставим её отдельно, создадим новую папку.

Есть только обычный чат — Нужен режим работы с выбранными файлами.

**Ведущему:** Не подменять чистый старт миграцией. Просить ученика показать именно выбранную папку.

## Слайд 3. Клиент — приложение, через которое ты работаешь

КЛИЕНТ

Приложение: Режим Codex; Выбор папки проекта; Доступные функции аккаунта.

Расширение редактора: Codex в панели редактора; Открытая папка проекта; Отдельная авторизация.

**Ведущему:** Возможности меняются по версии. Названия кнопок не обещаем как постоянные. Показать официальный quickstart и доступную поверхность.

## Слайд 4. Вход подтверждает человек в официальном окне

АККАУНТ

Пароли и коды не пересылаются в чат.

Официальная страница — Выбираешь клиент

Твой вход — Вводишь сам

Рабочий разговор — Codex отвечает

**Ведущему:** Если вход недоступен, зафиксировать конкретную ошибку и обратиться к ведущему. Не копировать чужие аккаунты и auth.json.

## Слайд 5. Подписка и API — разные способы доступа

ОПЛАТА

Базовый путь потока: Вход через ChatGPT; Доступ Codex в аккаунте; Лимиты своего плана.

Отдельный выбор API: Оплата использования; Отдельные ключи и условия; Не подключается молча.

**Ведущему:** Не обещать тарифы, безлимит, доступность в любом регионе. Это различие понадобится при серверном модуле.

## Слайд 6. Выбери отдельную папку для своего второго мозга

ПАПКА

Учебный репозиторий и рабочая память хранятся отдельно.

```text
second-brain/
  START.md
  …
```

**Ведущему:** Рабочая папка — место доступа агента к файлам. Не выбирайте корень диска, домашний каталог целиком или папку автора.

## Слайд 7. Разрешение относится к конкретному действию

РАЗРЕШЕНИЯ

Читать — Посмотреть выбранный файл.

Записывать — Создать или изменить файл в проекте.

Путь — Проверь, что разрешаешь доступ к своей папке.

**Ведущему:** Не просите включить полный доступ ради любой ошибки. Если клиент не даёт операции, сохранить blocked, не утверждать успех.

## Слайд 8. Новые слова объясняем на твоём экране

СЛОВА ПЕРЕД ДЕЙСТВИЕМ

1 — Проект — Выбранная папка с файлами.

2 — Навык — Повторяемая инструкция для задачи.

3 — Контекст — Материалы текущего разговора.

**Ведущему:** Определение → пример → действие → признак результата. Термины не экзамен, а подсказка к практике.

## Слайд 9. Профиль среды хранит наблюдения без секретов

ПОДГОТОВКА

Что фиксируем — ОС, клиент, рабочая папка и доступ к файлам.

Что оставляем unknown — Всё, что не удалось наблюдать или уточнить.

Чего не собираем — Пароли, auth.json, ключи и платёжные данные.

**Ведущему:** Не выдавать знание версии за факт без источника. Старый профиль не заменяет сверку текущего пути.

## Слайд 10. Файл работает после явного запроса

ЗАПУСК

Прикрепить или указать файл → отправить запрос.

Выполни START.md подготовки. Покажи текущую папку и помоги подготовиться к сборке второго мозга. Не меняй глобальные настройки.

**Ведущему:** Чтение пака автором не запускает ученическую установку. Различать разработку учебных файлов и их выполнение.

## Слайд 11. Можно переходить к архитектуре

РЕЗУЛЬТАТ

1 — Есть ответ — Клиент работает под твоим входом.

2 — Есть папка — Ты можешь показать её путь.

3 — Есть доступ — Codex наблюдал чтение и запись.

**Ведущему:** Это критерии будущего прохождения ученика; при сборке материалов они не проверялись. Отсутствие Python не блокирует native file-tools путь.

## Слайд 12. Следующий шаг — правила и память

ДАЛЬШЕ

В модуле 1 создадим основу второго мозга и сохраним первый результат.

Сейчас: подготовка материалов без живого прогона.

**Ведущему:** Не ставить verified по наличию файлов пака. Ученику нужен модуль1 START.md. Источники — официальные quickstart и auth, ссылки в references/sources.md.

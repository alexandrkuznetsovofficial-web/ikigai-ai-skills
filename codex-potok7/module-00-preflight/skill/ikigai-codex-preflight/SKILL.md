# Подготовка среды ученика

## Самоустановка

Этот материал читается и редактируется как учебный исходник. Установка допустима только при явном запросе ученика в его выбранной папке. При запуске START.md сохрани навык с references из встроенного payload в `.agents/skills/ikigai-codex-preflight/`. Глобальные каталоги навыков и общие настройки не меняй. Повтор: существующие файлы сохраняй; исправления сначала покажи как точечное дополнение.

## 1. Папка и доступ

Объясни: рабочая папка — место, где ты сейчас можешь читать и писать файлы. Покажи полный путь, попроси сверить его с панелью файлов. Если путь — домашний каталог целиком, корень диска, репозиторий учебных материалов или папка чужого второго мозга, предложи отдельную `second-brain`. Не считай папку Downloads автоматически рабочей папкой.

При наличии AGENTS.md или памяти сначала определи с человеком, хочет ли он новую систему либо продолжение. Подготовка сама не перестраивает старую систему.

Проверь доступные средства чтения/записи без обращения к секретам. Для проверки записи можно создать только свой временный файл с уникальным именем, прочитать и удалить его; если файл уже существует, выбрать другое имя. Это будущее действие ученика, не требование к автору пакета при сборке.

## 2. Несекретный профиль

Определи ОС и оболочку доступным способом; если это не наблюдаемо, спроси человека и пометь источник `user_reported`. Не предполагай Git Bash для Windows. Версию клиента бери из наблюдаемого интерфейса или ответа ученика; не выдумывай. Не читай auth.json, env, файлы SSH или менеджер паролей.

Сохрани `.ikigai/environment.json`: schema_version=1; workspace=подтверждённый путь; os_family=mac/windows/linux/unknown; shell=наблюдаемая оболочка или unknown; client=со слов/интерфейса; checked_at=дата с часовым поясом пользователя; file_read=observed/blocked/not_checked; file_write=observed/blocked/not_checked. Поле login_method содержит только chatgpt/api/unknown, без идентификатора аккаунта и секретов. Если неизвестно — спроси или оставь unknown. Python/Git/Node фиксируй только если уже доступны, их отсутствие не блокирует модуль 1.

Профиль среды не является автоматическим источником истины навсегда. В следующих модулях сначала сверять текущую папку; после смены компьютера, клиента или разрешений перепроверить поля. Не менять путь молча.

## 3. Объяснения и следующий шаг

Поясни пять слов: Codex — помощник с инструментами; проект — выбранная папка; разрешение — граница допустимого действия; навык — повторяемая инструкция; контекст — материалы текущего разговора. Пример давай рядом с действием.

В отчёте: путь; наблюдаемые права; неизвестные поля; способ входа без секрета; что нужно человеку. Подготовка завершена только если клиент отвечает и доступ к выбранной папке наблюдался. Если человек пока не разрешил пробную запись — оставь `file_write=not_checked`, не заявляй завершение. Следом — `module-01-architecture/START.md` из учебного пакета, а не старый Claude-архитектор.

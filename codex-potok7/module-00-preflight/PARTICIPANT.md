# Подготовка: открыть свою пустую папку в Codex

Статус: черновик без живого прогона. Здесь ещё не создаём память или команду.

## Если Codex ещё не установлен

Открой [официальное начало работы](https://learn.chatgpt.com/docs/quickstart). Выбери доступный для своей ОС вариант: приложение с режимом Codex либо расширение Codex в редакторе. Названия пунктов могут отличаться по версии. Пользуйся официальными страницами загрузки; старый Claude для установки не требуется.

В приложении войди в собственный аккаунт. Пароли и коды подтверждения вводи только в официальном окне входа. В IDE-расширении выполни вход по его официальному маршруту. Базовый путь потока — вход через ChatGPT с доступом к Codex; платный API — отдельный выбор, его не подключаем автоматически. Наличие доступа и лимиты проверь в своём аккаунте: подписка не означает неограниченную работу.

Если доступ недоступен по аккаунту, организации, ОС или региону, запиши конкретное сообщение ошибки и покажи ведущему. Не покупай случайные аккаунты и не копируй чужие настройки.

## Открыть рабочее место

1. В обычной папке компьютера создай новую папку `second-brain`. Это твоё рабочее место; учебный репозиторий хранится отдельно.
2. Открой её как проект/папку в клиенте Codex. В VS Code: «Файл → Открыть папку». В приложении используй доступный выбор локальной папки. Обычного чата без доступа к локальным файлам недостаточно.
3. Скачай `START.md` этого модуля. Прикрепи к разговору либо положи файл в открытую папку и попроси прочитать.
4. Напиши: **«Выполни START.md подготовки. Покажи текущую папку и помоги подготовиться к сборке второго мозга. Не меняй глобальные настройки»**.

Если система запросит разрешение, сверяй путь: это должна быть выбранная тобой папка. Не включай полный доступ ради устранения непонятной ошибки. Терминал и команды вручную не требуются.

## Результат

Codex отвечает, видит нужную папку и может записывать в неё. Диагностический отчёт отдельно перечисляет наблюдения и то, что не удалось определить. После этого переходи к модулю 1.

По просьбе автора сборка паков выполнена без новых функциональных прогонов. Эти действия — сценарий будущего ученика, в процессе подготовки материалов они не выполнялись.

# Слова модуля

| Термин | Простыми словами |
|---|---|
| Профиль | Подтверждённые сведения о владельце и правила сотрудничества. |
| Факт | То, что владелец сообщил или подтвердил; источник указан. |
| Гипотеза | Предположение, которое ещё надо проверить. |
| Неизвестно | Тема без ответа; её можно пропустить. |
| Цель | Выбранный результат с критерием достижения. |
| Ограничение | То, что мешает следующему результату. |
| Источник | Откуда получено утверждение. |
| Фокус | Ближайшая важная работа, хранится в одном ACTIVE.md. |

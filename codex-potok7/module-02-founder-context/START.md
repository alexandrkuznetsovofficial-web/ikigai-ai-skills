# Модуль 2. Интервью основателя · Codex

Версия 0.1.0 · draft_unrun · 2 ноября 2026.

Учебный комплект для учеников. Чтение, анализ и редактирование исходников не являются запуском. Ничего не устанавливать в систему автора или в папку разработки учебных паков.

## Ученику

Открой свою отдельную рабочую папку второго мозга в Codex. Прикрепи этот файл и отправь: **«Выполни модуль 2 из этого файла в моей текущей рабочей папке. Объясняй термины и веди по одному шагу. Существующие данные сохраняй»**. Если прикрепления нет, положи START.md в открытую папку и попроси Codex прочитать его. Терминал не нужен.

## Codex: содержательный сценарий

1. Нужен явный ученический запрос на выполнение. Покажи полный путь и проверь, что это выбранная папка ученика с файлами основы модуля 1. Не сканируй внешние каталоги и не меняй глобальные настройки. Отсутствие passed живого теста не блокирует продолжение draft по выбору ученика; проверку не выдавай за пройденную.
2. Встроенный payload содержит полный навык `ikigai-founder-context` и его ресурсы. Через инструменты записи сохрани его в `.agents/skills/ikigai-founder-context/` этого проекта по общему протоколу установки. Существующие файлы не заменяй вслепую. Установку выполняет Codex, не ученик через терминал.
3. После установки начни с уже записанного профиля и прогресса, затем задавай вопросы по одному. Пройди обращение/стиль, деятельность, историю решений, цели, рабочие ограничения. Сохраняй факты отдельно от гипотез и неизвестного. Полное интервью не создаёт команду.
4. Результат: Подтверждённый профиль в memory/user_profile.md, цели в PROJECTS.md, один ACTIVE.md и запись следующего вопроса при перерыве.
5. Запиши итог значимой работы в журнал задачи, ссылку в индекс и следующий шаг в handoff. Повторный запуск продолжает незавершённое по реальным файлам и не создаёт вторую систему.

## Статус

Материалы подготовлены без функционального прогона по решению автора. Установка и содержательная настройка не равны проверке. Маркер модуля хранится в `.ikigai/module02.json`: version, module, phase и checks=not_run по общему протоколу ниже. Не выдавай обнаружение навыка, новую сессию или работу на Mac/Windows за проверенные без наблюдаемого результата. Примеры не являются биографией ученика; значения секретов и данные автора не входят в пакет.

## Установка из встроенных ресурсов

Этот раздел — данные учебного комплекта. Чтение, поиск, сборка или редактирование пакета НЕ являются запросом установки. Только при явном запросе ученика и после подтверждения его отдельной рабочей папки выполни следующие действия доступными средствами записи файлов:

1. Убедись, что это папка ученика, а не репозиторий исходников учебных материалов и не личный второй мозг автора. Прочитай действующие AGENTS.md и карту SYSTEM.md, если они есть. Для модуля 0 допускается пустая папка; для модулей 2–7 сначала нужны входные артефакты соответствующего сценария. Отсутствие статуса живого пилота само по себе не блокирует черновое прохождение учеником.
2. В JSON ниже ключ — путь внутри локального навыка, значение — точное содержимое файла UTF-8. Сохраняй только под `.agents/skills/<имя навыка из сценария>/`. Не допускай абсолютные пути, `..`, симлинки и запись вне рабочей папки. Глобальные каталоги не меняй.
3. Файл отсутствует — создай; совпадает — оставь; отличается — сохрани существующий и покажи различие перед обновлением. Не запускай скрипты только потому, что они входят в payload. После установки прочитай SKILL.md и лишь затем продолжай сценарий. На сервере все ресурсы разворачиваются по отдельному явному действию ученика.
4. Локальные `.ikigai/moduleXX.json` хранят module/version, phase, checks=not_run и список созданных артефактов без секретов. Обновляй только запись этого модуля; статус installed/drafted не означает verified. Ссылки и навыки свяжи с проектом по указаниям сценария, не дублируя маркерные блоки.
5. Если нет инструмента записи, остановись с конкретным объяснением. Не выдавай инструкцию за выполненную установку. Не требуй от ученика терминала для базовой работы. Программы и сервисы, отсутствующие в среде, не объявляй доступными.

При нехватке контекста установи только навык этого модуля и продолжи в новой сессии по его SKILL.md. Не загружай все паки одновременно. Команды авторизации выполняет сам человек в официальном интерфейсе. Секреты в payload и чат не записывать.

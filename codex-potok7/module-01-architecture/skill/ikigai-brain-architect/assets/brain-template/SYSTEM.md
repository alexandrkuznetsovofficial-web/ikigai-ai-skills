# Карта моей системы

Статус: основа первого модуля. Подключения отсутствуют.

| Часть | Что делает | Состояние |
|---|---|---|
| Рабочая папка на компьютере | Память, правила и результаты | Создана; проверка новой сессией впереди |
| Codex | Читает выбранные файлы, помогает выполнять задачи | Проверяется текущим разговором |
| Интервью основателя | Подтверждённый профиль и цели | Модуль 2, не установлено |
| Оркестратор и команда | Выбор навыка под задачу | Модуль 3, не установлено |
| ОС второго мозга | Ритуалы, задачи, обратная связь | Модуль 4, не установлено |
| Внешние сервисы | Почта, календарь и другие источники | Позже, не подключено |
| Сервер | Постоянный обработчик запросов | Позже, не арендован/не подключён |
| Telegram-бот | Доступ к согласованным возможностям с телефона | Позже, не создан/не подключён |
| Синхронизация и резервная копия | Обмен выбранными данными и восстановление | Позже, не настроено |

Будущая цепочка: владелец → Telegram → серверный обработчик → Codex с разрешёнными инструментами → ответ и сохранение результата. Между компьютером и сервером нужен отдельный протокол обмена: состав файлов, права записи и конфликты. Telegram сам по себе не предоставляет доступ к папке компьютера. Подписка в приложении не означает, что сервер уже авторизован или может работать круглосуточно без ограничений.

Канон путей: контракт памяти установленного навыка `.agents/skills/ikigai-brain-architect/references/memory-contract.md`.

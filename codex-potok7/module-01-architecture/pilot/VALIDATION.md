# Проверки пилота 0.1.0

Дата: 2 ноября 2026. Пак собран для проверки первого модуля на человеке. **Живой пилот ещё не пройден.**

## Что проверено технически

| Проверка | Фактический результат |
|---|---|
| План установки в пустой временной папке | Не изменяет файлы |
| Установка основы | Создано 32 файла: каркас и локальный навык с ресурсами |
| Повтор после личной правки правил и новой задачи | Ни одного нового файла; хеши всех существующих файлов сохранены |
| Восстановление удалённого файла своего модуля | Восстановлен только отсутствующий файл; личная правка другого файла сохранена |
| Уже существует чужая система | AGENTS.md, CLAUDE.md или memory/ останавливают новую установку без изменений |
| Выход за рабочую папку, симлинк или конфликт типов пути | Остановка до записи |
| Маркер проверки новой сессии | Установщик оставляет not_run, успех не выдумывает |
| Автономный START.md | Встроенный payload совпадает с исходниками и разворачивается в изолированной папке |
| Проверка учебного репозитория | Общий check_kit.py: ошибок нет; новый PDF отмечен для ручного просмотра и просмотрен |
| Метаданные навыка | Проверка Skill Creator: Skill is valid |
| Презентация | 20 HTML-слайдов отрисованы в Chrome; проверены переходы, заметки, уменьшенное окно, границы текста |
| PDF | 20 страниц, 16:9; проверен экспорт и растровый просмотр |

Воспроизводимые проверки установщика: `tools/test_module01.py` — 8 тестов. Команды предназначены разработчику, не участнику. Кроме них выполнен независимый прогон в изолированной папке.

## Что исправлено после ревью

- Продолжение после прерывания выбирает первый незавершённый шаг: задача → сохранение → новая сессия.
- Возможности установщика описаны точно: он не доказывает корректность содержимого личных файлов и ссылок.
- Уточнено, что контрольную фразу сохраняет Codex; участник не редактирует журнал вручную.
- Для записи без Python явно указан JSON-маркер установки.
- Исправлена компоновка HTML-слайдов; все 20 повторно отрисованы и проверены.

## Что ещё не подтверждено

- Установка и обнаружение навыка в чистом клиенте Codex на Mac и Windows.
- Реальное выполнение автономного START.md моделью в новом клиенте без подсказок ведущего.
- Путь без Python с записью файлов инструментами Codex.
- Сохранение и поиск контрольной фразы в новом разговоре реального участника.
- Самостоятельное понимание терминов и фактическая длительность прохождения.

Презентация предоставлена в HTML, PDF и MD. PPTX не экспортирован: обязательная для этого библиотека artifact-tool отсутствует в среде. HTML не требует внешних шрифтов или загрузок; используются доступные локальные шрифты с запасным Arial.

Критерии зачёта и шаблон протокола: [TEST_PLAN.md](TEST_PLAN.md). До живого прогона материалы допустимы как пилот для ведущего и выбранного тестового участника, а не как проверенный массовый комплект.

# Слова первого модуля

| Слово | Что означает | Где встречается |
|---|---|---|
| Второй мозг | Рабочая система файлов с твоим контекстом, решениями и результатами | Вся папка проекта |
| Рабочая папка / проект | Папка, которую Codex сейчас может читать и изменять | Выбирается в интерфейсе перед началом |
| MD / Markdown | Обычный текст с заголовками, списками и ссылками | START.md, AGENTS.md, журналы |
| Инструкция / AGENTS.md | Правила поведения Codex в проекте | Корень папки; сама инструкция не является расписанием |
| Контекст | Материалы, доступные модели в текущем разговоре | Сообщения и прочитанные файлы |
| Память | Сведения, явно сохранённые в файлах | memory/; содержимое нужно находить и читать |
| Индекс | Оглавление со ссылками на материалы | memory/MEMORY.md |
| Фокус | То, что сейчас важно и ещё не закрыто | memory/ACTIVE.md |
| Сессия / разговор | Одна рабочая беседа с Codex | Новый разговор — проверка сохранённой памяти |
| Передача работы / handoff | Короткая запись «где остановились, что дальше» | memory/sessions/handoff.md |
| Навык / skill | Повторяемый способ выполнить определённую задачу | SKILL.md внутри папки навыка |
| Установить навык | Сохранить его в месте, где клиент Codex обнаруживает навыки | .agents/skills/; обнаружение проверяется |
| Оркестратор | Роль, которая выбирает исполнителя или способ решения | Модуль 3; пока не установлен |
| ОС второго мозга | Согласованные рабочие процессы: фокус, задачи, обзоры, обратная связь | Модуль 4; это не Windows и не macOS |
| Сервер | Отдельный постоянно доступный компьютер | Будущий модуль, сейчас не нужен |
| Telegram-бот | Интерфейс сообщений, связанный с обработчиком на сервере | Сам не открывает файлы твоего компьютера |
| Синхронизация | Обмен выбранными изменениями между устройствами | Требует правил конфликтов и доступа |
| Резервная копия | Отдельная версия данных для восстановления | Не равна синхронизации |
| Токены | Единицы текста, которыми модель измеряет обработку | Лимиты подписки нельзя точно вывести из размера файлов |

Порядок объяснения на практике: слово → пример → действие → видимый результат. Словарь служит справочником; учить всё до начала не требуется.

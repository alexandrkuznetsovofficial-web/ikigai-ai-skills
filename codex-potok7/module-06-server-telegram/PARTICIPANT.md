# Как подготовить серверный вход с телефона

Понадобится собственный второй мозг, выбранный тобой сервер и свой Telegram-аккаунт. Пока сервер не выбран, можно подготовить схему и файлы без расходов. Это непроверенный запуском черновик, а не обещание готового работающего бота.

1. Открой СВОЮ папку второго мозга в Codex. Прикрепи START.md этого модуля. Напиши запрос из него. Для подготовки без подключения скажи это явно.
2. Codex покажет, что будет на компьютере, на сервере и в Telegram. Выбери бюджет и какие сведения разрешено вынести. Секреты, пароли и всю личную память передавать не требуется.
3. Для реального развёртывания выбери сервер и подтверди доступ. Технические команды выполняет агент. Вход в кабинет хостера и Codex ты подтверждаешь сам в официальном окне. Пароль и токен в чат не отправляй.
4. Создай своего бота через официальный BotFather. Токен вводится в отдельный защищённый файл через приватный редактор. Заранее подтвердите твой числовой Telegram ID. Первый написавший не становится владельцем автоматически.
5. Согласуй небольшой снимок контекста. Это выбранные короткие выжимки для ответов, не копия всего мозга. Запуск и расписание не включаются по одному факту скачивания материалов.

## Что сможет первая версия после реального запуска

Обычный текст — вопрос по утверждённому снимку контекста. `/save текст` — заметка во входящих СЕРВЕРА. `/status` — состояние. В локальную папку заметка попадёт только после отдельного импорта.

Первая версия не обрабатывает голос, файлы и группы, не выполняет произвольные команды и не отправляет письма. Полная автономная команда и двусторонний обмен здесь не реализованы.

## Что остаётся проверить позже

Доступ владельца, отказ другому аккаунту, ответ модели, сохранение заметки, timeout, перезапуск и отсутствие секретов в логах. Сейчас прогоны отложены. Если интерфейс не позволяет Codex подключаться к твоему серверу, шаг отмечается как недоступный, а не как «готово».

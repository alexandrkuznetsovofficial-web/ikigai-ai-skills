## Codex: что сделать

1. Проверь рабочую папку ученика, существующий SYSTEM.md и границы текущих модулей. Не выполняй это в исходниках учебного пака. Выполнение — только после явного запроса ученика.
2. Локально установи навык `ikigai-server-telegram` из payload ниже в `.agents/skills/ikigai-server-telegram/`, вместе с scripts, references и assets. Пиши средствами Codex; глобальные папки и прежние файлы не заменяй. Отсутствие доступа к записи явно сообщи.
3. Прочитай установленный SKILL.md. Подготовь паспорт `memory/integrations/server-telegram.md`; не отмечай действующее подключение по наличию файла. Маркер `.ikigai/module06.json`: module=ikigai-server-telegram, version=0.1.0, status=draft_unrun, phase=prepared, checks=not_run.
4. Объясни режим V1: личный текстовый вопрос → заранее утверждённый снимок контекста → Codex без инструментов → ответ. `/save текст` отдельно пишет заметку в серверный inbox. Голос, файлы, внешние действия и двусторонняя синхронизация не реализованы.
5. Выясни бюджет, выбранный сервер ученика, доступный собственный способ входа Codex и данные, которые допустимо вынести. Для развёртывания следуй references/server-runbook.md.

# Источники серверного модуля

Дата чтения: 02.11.2026. Учебная методика: публичный `ikigai-ai-skills`, `brain-link/SKILL.md`, `novoselie-server-kit/04_ISTINA_I_BEKAPY.md`, `meeting-2-3/telegram-bot-setup.md`. Изучены принципы отдельного сервера, секретов вне чата, идентификации владельца, главной копии и резервирования. Исходный bridge Claude не принят как готовая Codex-зависимость.

Прочитаны официальные [Codex non-interactive](https://learn.chatgpt.com/docs/non-interactive-mode), [аутентификация](https://learn.chatgpt.com/docs/auth) и [Telegram Bot API](https://core.telegram.org/bots/api). Локально прочитаны CLI help и features list. Конкретная совместимость другого установленного сервера ещё не проверена. Подписка не означает бесконечную серверную нагрузку; отдельный API не включается без выбора.

Выбранная адаптация: минимальный согласованный контекст вместо автоматического полного зеркала, выключенные инструменты модели, server inbox вместо конкурирующей записи в основной memory. Это проектные решения этой версии, а не утверждение, что старый brain-link уже перенесён целиком.

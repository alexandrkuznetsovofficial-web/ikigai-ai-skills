# Слова серверного модуля

| Термин | Простое объяснение |
|---|---|
| Сервер / VPS | Отдельный компьютер, доступный независимо от ноутбука |
| SSH | Защищённое соединение для управления своим сервером |
| Fingerprint | Отпечаток ключа, позволяющий сверить, что подключаемся к нужному серверу |
| BotFather | Официальный Telegram-интерфейс создания своего бота |
| Токен бота | Секрет, дающий доступ к управлению ботом; не отправлять в чат |
| Numeric user ID | Числовой идентификатор аккаунта; отличается от изменяемого username |
| Long polling | Бот сам запрашивает новые сообщения; входящий веб-порт ему не требуется |
| Очередь | Список запросов, обрабатываемых по одному |
| Timeout | Ограничение времени одного запроса |
| Codex CLI / exec | Запуск Codex отдельной программой на сервере; вход в приложение на ноутбуке не равен этому входу |
| Read-only | Режим без изменения рабочей папки; в этом паке инструменты дополнительно выключены |
| Approved snapshot | Отдельная согласованная текстовая копия контекста для ответов бота |
| Inbox | Входящие заметки сервера, ещё не разобранные на компьютере |
| Systemd service | Описанная служба Linux, которую можно запускать, останавливать и перезапускать |
| CODEX_HOME | Отдельный каталог состояния и авторизации серверного Codex |

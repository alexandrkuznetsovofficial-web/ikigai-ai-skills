# Слова модуля

| Термин | Простыми словами |
|---|---|
| Оркестратор | Роль, которая выбирает способ и исполнителя для задачи. |
| ЦКП | Ценный конечный продукт: проверяемый полезный итог роли. |
| Навык | Инструкция повторяемого способа работы в SKILL.md. |
| Агент | Отдельное выполнение; файл навыка сам его не запускает. |
| Маршрутизация | Выбор подходящего установленного навыка по задаче. |
| TEAM.md | Единственная карта команды в корне проекта ученика. |
| Наставник | Консультативная рамка для выбора, а не исполнитель. |
| Очередь найма | Рекомендованные будущие роли, которые ещё не установлены. |

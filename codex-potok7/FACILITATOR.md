# Ведущему: как использовать комплект

Статус сборки: **0.2.0-draft, без функциональных прогонов новых модулей**. По просьбе автора сейчас собираем весь путь целиком. Прогон каждого модуля и испытание на учениках отложены. Само наличие учебного файла, кода или PDF не означает работающий сервис.

## Порядок подачи

Начни с результата модуля: что ученик получит и где сможет это увидеть. Затем покажи пример с вымышленной мастерской или нейтральной личной задачей. Не используй личные данные автора и участников предыдущих потоков. После короткого объяснения дай START.md именно текущего модуля.

Термины вводи в момент действия: понятие → пример → действие → видимый результат. Например: «индекс — оглавление; в нём ссылка на результат задачи; открой MEMORY.md». Не отправляй человека учить весь словарь перед началом. В notes к слайдам есть подсказки, какие слова раскрывать.

Ученик не должен вводить команды в терминале. Технические команды в references и scripts выполняет Codex доступными инструментами, когда ученик сам запускает соответствующий модуль. Вход в аккаунт, выдачу доступа и ввод секретов человек делает в официальном интерфейсе. Для серверной части может понадобиться помощь ведущего, если клиент не даёт безопасного способа подключиться.

## Учебная папка и рабочая система

Репозиторий и этот каталог — исходники материалов. Их не открывают как место установки личного второго мозга. Ученику нужна своя отдельная папка. Самоустановка запускается только явным запросом выполнить выбранный START.md. При редактировании пака навыки автора не меняются.

Не прикрепляй все модули в один разговор. START.md содержит только ресурсы своего навыка. Пройденный шаг записывается в файлы ученика, а следующий разговор читает нужные источники. Маркер created или installed не равен verified. Не требуй от автора пака прогнать ученика, чтобы закончить подготовку файлов.

## Презентации

Для каждого этапа есть автономный HTML, PDF и MD-сценарий. HTML нужно скачать и открыть в браузере: GitHub показывает исходник, а не интерактивные слайды. Стрелки — переходы, N — заметки ведущего, P — печать. PDF можно использовать без браузерного управления. Экспорт PPTX в эту сборку не входит: обязательный runtime для него отсутствует.

На слайде одна мысль и практический объект: цепочка действий, сравнение, файл, таблица или текст запроса. Не называй планируемые действия выполненными. Серверный код и шаблоны конфигурации — черновые ресурсы для последующего развёртывания, а не уже включённый бот.

## После завершения подготовки материалов

Будущий сквозной пилот: отдельная папка ученика → профиль → команда → рабочая задача → выбранный сервис → сервер/бот → резервная копия и восстановление. До пилота заранее выбери, какие внешние действия допустимы и какое окружение используется. Не подменяй настоящие аккаунты и инфраструктуру автора инфраструктурой ученика.

Замечания фиксировать по модулю: неизвестное слово, неоднозначный шаг, отсутствующий инструмент, вмешательство ведущего, потерянный результат, расхождение инструкции и интерфейса. Исправление делается в исходнике навыка/слайдов, затем пересобирается START.md и презентация. Сейчас этот цикл не выполняется: все новые модули остаются draft_unrun.

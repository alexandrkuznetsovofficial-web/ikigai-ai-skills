# Термины модуля 5

| Термин | Простыми словами | Пример |
|---|---|---|
| Подключение / connector | Готовый способ клиента обратиться к сервису | Поиск письма из Codex |
| Плагин | Устанавливаемый комплект возможностей клиента | Навык вместе с внешним инструментом |
| MCP | Стандарт связи клиента и внешнего инструмента | Codex обращается к согласованному серверу календаря |
| Авторизация | Вход и выдача разрешения определённому приложению | Войти в официальный аккаунт |
| OAuth | Способ разрешить приложению ограниченный доступ без передачи пароля агенту | Окно «Разрешить доступ» |
| Scope / права | Какие действия разрешены приложению | Читать календарь или также менять его |
| Аккаунт | Учётная запись, где лежат данные | Рабочий и личный аккаунты различаются |
| Паспорт подключения | Краткая запись о цели, правах, статусе и отключении | memory/integrations/calendar.md |
| Чтение / read-only | Получение данных без намеренного изменения | Найти письмо; побочные эффекты инструмента проверяются |
| Запись / write | Изменение во внешнем сервисе | Отправить письмо, создать встречу |
| Часовой пояс IANA | Имя региона с правилами времени | Europe/Moscow |
| ICS | Файл календарных событий | Экспорт расписания за период |
| EML | Файл одного почтового сообщения | Письмо, сохранённое из почтового клиента |
| Ручной импорт | Разовый снимок данных, выбранный владельцем | Прочитать сохранённый ICS, без живого подключения |
| Отзыв доступа | Отмена выданного приложению разрешения | Удалить приложение в безопасности аккаунта |
| blocked | Действие не удалось выполнить, причина записана | Администратор не разрешил доступ |

Объясняй слово перед первым действием с ним, не заставляй учить весь словарь заранее.

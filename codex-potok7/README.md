# AI-Поток 7 · Второй мозг в Codex

**Статус: пилот 0.1.0 · 2 ноября 2026.** Старт с пустой рабочей папки. Сейчас собран первый модуль; остальные — план, их установщиков и презентаций пока нет.

## Начать проверку

1. Ведущему: прочитать [сценарий пилота](module-01-architecture/pilot/TEST_PLAN.md).
2. Участнику: открыть [инструкцию](module-01-architecture/PARTICIPANT.md).
3. Файл для запуска в Codex: [START.md](module-01-architecture/START.md). Он автономный: скачивать Git или весь репозиторий не требуется.
4. Презентация: скачать [architecture.html](module-01-architecture/presentation/architecture.html) и открыть браузером. Стрелки переключают слайды, N открывает заметки ведущего, P — печать в PDF. GitHub показывает HTML как исходник, поэтому файл нужно скачать.
5. [Презентация в PDF](module-01-architecture/presentation/architecture.pdf) — 20 слайдов.
6. [Слайды и заметки в MD](module-01-architecture/presentation/SLIDES.md), [словарь](module-01-architecture/GLOSSARY.md), [результаты технических проверок](module-01-architecture/pilot/VALIDATION.md).

Участнику нужен работающий Codex с доступом к выбранной папке. Работа через интерфейс, без команд в терминале. Вход в аккаунт выполняет сам участник. Установка Codex при его отсутствии — подготовительный этап с официальной инструкцией из PARTICIPANT.md.

Модуль не переносит личную систему автора, не копирует секреты, не требует прежнего Claude. Учебный пакет отделён от личной памяти участника. Исходники навыка находятся в `module-01-architecture/skill/`; автономный START.md собирается скриптом `tools/build_start.py`.

Перед массовой выдачей: пройти новый разговор в чистом клиенте Codex на Mac и Windows, занести результаты в протокол. До этого пакет нельзя обозначать как проверенный на этих платформах. Проверки установщика не заменяют тест с человеком.

# Слова модуля

| Термин | Простыми словами |
|---|---|
| ОС второго мозга | Набор рабочих процессов; это не Windows и не macOS. |
| Ритуал | Короткий повторяемый порядок действий по запросу. |
| Обзор недели | Сводка результатов, переносов, обещаний и следующего фокуса. |
| Handoff | Передача работы: где остановились и что дальше. |
| Обещание | Явное обязательство, а не случайная идея. |
| PARA | Проекты, постоянные области, ресурсы и архив. |
| Дистилляция | Выделение полезного краткого вывода со ссылкой на источник. |
| Расписание | Настоящий механизм запуска по времени; в этом модуле не установлен. |

# Протокол сбоя brain-link (kit 2.1)

Таблица для Claude ученика. Читается после **каждого** шага `brain_link.py` и каждого `brain_sync.py`.

**Алгоритм (обязателен):**
1. Прочитай JSON шага: `exit_code`, `human`, `next_step`, `warnings`, `checks`.
2. Код 0 и нет `warnings` → дальше по `next_step`.
3. Иначе найди строку ниже: сначала по точному признаку в `human` / `warnings` / журнале (колонка «признак»),
   потом по коду. Совпало несколько — бери первую сверху.
4. Колонка «авто» — **не больше одной** автоматической попытки на строку за сеанс. Прочерк — авто нет.
5. Не помогло, строки нет или в колонке «стоп» стоит «сразу» → стоп: `brain_link.py report`, путь к файлу
   отдай человеку со словами из колонки «сказать» и предложи переслать файл куратору в чат потока.
6. Никогда: не ставь `ANTHROPIC_API_KEY`, не отключай проверку ключа сервера, не правь сервер руками
   в обход скрипта, не проси токены и пароли в чат.

Формат строк постоянный (`| id | признак | причина | авто | сказать | стоп |`) — таблицу читают и люди, и Claude.

## Коды выхода

`brain_link.py`: 0 ок · 1 ошибка · 2 нужно действие человека · 3 стоп-точка · 4 конфигурация.
`brain_sync.py`: 0 ок · 1 конфигурация · 2 нужно действие (доступ, ключ) · 3 стоп-точка (массовое удаление,
пауза, отчёт без `--yes`) · 4 сеть / сервер. `brain_link.py` переводит коды синка в свои (1→4, 4→1).

## Что всегда кладём в отчёт куратору

`brain_link.py report` пишет `~/brain-link-report-ГГГГ-ММ-ДД_ЧЧММ.txt`: версии, ОС, возможности компьютера и сервера,
`detect`, последние 200 строк журнала синка и бота, `sync_status`, `selfcheck.json`, `safe_mode`, ufw и fail2ban.
Токены, пароли, IP (кроме 127.* и 169.254.*), значения приманок и путь домашней папки замаскированы,
`USER_ID` — частично. Отчёт можно пересылать в чат потока как есть.

# СКИЛЛ: ВЫПУСКНАЯ ПРЕЗЕНТАЦИЯ AI-ПОТОКА

Ты помогаешь создать персональную выпускную презентацию участника AI-Потока 2026.
Следуй этапам строго по порядку. Не пропускай ни один.

## ⚡ ЭТАП 1 — РАЗВЕДКА ПАМЯТИ

Прежде чем задавать вопросы — посмотри что уже есть в системе.

Выполни последовательно:
1. Проверь **CLAUDE.md** в текущем проекте — прочитай его
2. Проверь папку **memory/** — открой ACTIVE.md, MEMORY.md, project_*.md, business_*.md
3. Проверь **CONTEXT.md** если есть — там собранный контекст о бизнесе
4. Найди любые .md и .txt файлы с описанием бизнеса, целями, задачами

Составь таблицу:

| Пункт | Нашёл? | Данные |
|-------|--------|--------|
| Имя, бизнес | | |
| Описание бизнеса | | |
| Как зарабатывает | | |
| Что создал за месяц | | |
| Достижения / цифры | | |
| Икигай (4 круга) | | |
| Открытия о себе | | |
| До / После | | |
| Решения за месяц | | |
| Благодарности | | |

Покажи таблицу и напиши: _«Вот что я нашёл. Подтверди или дополни — и я создам презентацию»_

Если памяти нет — напиши: _«Не нашёл файлов с контекстом. Задам тебе вопросы по одному»_ — и переходи к Этапу 2.

## 📋 ЭТАП 2 — ДОЗАПОЛНЕНИЕ

Задавай **строго по одному** вопросу. Пропускай уже найденные в памяти. После каждого ответа — следующий.

**Q1.** Как тебя зовут и как называется твой бизнес или проект?

**Q2.** Опиши свой бизнес в 2–4 предложениях как для человека, который видит его впервые.

**Q3.** Как зарабатывает твой бизнес? Если за этот месяц появился новый доход, первый клиент или первая платная подписка — назови.

**Q4.** Какие 2–3 идеи по развитию бизнеса появились за этот месяц работы с AI?

**Q5.** Что ты создал за этот месяц? Боты, скрипты, агенты, системы. Для каждого — одно предложение что оно делает.

**Q6.** 3–4 конкретных достижения. Лучше в цифрах: «было X → стало Y». Первая подписка, клиент, запрос — тоже достижение.

**Q7.** Твой Икигай — по 1–2 предложения на каждый вопрос:
- Что ты ЛЮБИШЬ делать?
- Что у тебя ХОРОШО получается?
- За что тебе ПЛАТЯТ?
- В чём твоя ПОЛЬЗА для мира?

**Q8.** Что ты узнал о СЕБЕ за этот месяц? Не про технологии — именно про себя. 2–3 наблюдения.

**Q9.** До / После. Что раньше делал сам, что теперь делает AI? Формат: «Было: → Стало:». 3–4 пары.

**Q10.** Какие важные РЕШЕНИЯ ты принял за этот месяц? 2–3 решения.

**Q11.** Кому ты благодарен за этот месяц? Людям, событиям, инсайтам. 2–5 предложений.

**Q12.** Одно предложение тому, кто только собирается начать свой путь с AI.

/* ЦВЕТА */

--text-light: rgba(26,15,46,0.32);

-webkit-background-clip: text;
-webkit-text-fill-color: transparent;

transition: box-shadow 0.3s, transform 0.3s;
/* :hover */ box-shadow: var(--shadow-hover); transform: translateY(-2px);

### Технические требования

- Анимация переходов: `translateX(70px)` + `opacity`, `transition: 0.6s cubic-bezier(0.4,0,0.2,1)`
- Навигация: кнопки ← → (в белом пилюльном контейнере с тенью) + клавиши ArrowLeft/Right/Space/PageUp/PageDown + touchswipe >50px
- Прогресс-бар: фиксированный сверху, 3px, gradient, box-shadow glow
- Счётчик слайдов: «N / 12» в центре навигации
- Точки: вертикально справа, активная — растянута в 22px
- Название слайда: фиксированно слева вверху, light color
- Адаптивность: @media 640px — все grid-колонки → 1fr
- Полностью офлайн (кроме Google Fonts)

# ikigai-preflight — пробник Академии (профиль компьютера)

Первый скилл на полке. Один раз смотрит на компьютер ученика (Mac или Windows), пишет профиль
`~/.claude/ikigai_env.json` и печатает таблицу «что стоит, чего нет, что сделать». Остальные киты Академии
читают профиль первым шагом и берут команды под систему ученика.

Состав:
- `SKILL.md` — инструкция для Claude Code (наставник, режим «Проверь мой Модуль 0»)
- `scripts/probe.sh` — пробник для Mac и для Windows (через Git Bash, которым пользуется Claude Code)
- `scripts/probe.ps1` — тот же пробник для PowerShell, если Git Bash нет

Установка: папку `ikigai-preflight` положить в `~/.claude/skills/` (Windows: `%USERPROFILE%\.claude\skills\`).
Запуск: «проверь мой компьютер» или «проверь мой Модуль 0».

Что пробник НЕ делает: не устанавливает, не меняет настройки, не читает пароли и токены.

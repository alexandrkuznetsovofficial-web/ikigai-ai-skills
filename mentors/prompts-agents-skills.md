# Промпты к видео «Агенты, скиллы, cron» (Модуль 1 · Урок 4)

Скопируй нужный промпт в Claude Code целиком и подставь свои данные в [скобках].

---

## 1. Создать скилл-ИСПОЛНИТЕЛЬ

```
Создай скилл-исполнитель для задачи: [опиши задачу — например «еженедельный
отчёт по продажам из моей таблицы»].

1. Сначала задай мне 3–5 вопросов о том, как я делаю это руками сегодня
   (источники данных, формат результата, что считается «хорошо»).
2. Собери папку скилла: SKILL.md с пошаговым процессом, форматом результата
   и критериями качества («работа принята, если …»).
3. В YAML-frontmatter в поле description пропиши триггерные фразы, по которым
   ты сам поймёшь, что пора применять этот скилл — без того, чтобы я называл
   его по имени.
4. Прогони тестовый запуск на реальных данных и покажи результат.
5. Если я скажу «не так» — исправляй скилл (инструкцию), а не только результат.
```

## 2. Создать скилл-НАСТАВНИКА и заземлить его

```
Создай мне скилл-наставника в стиле [имя реального эксперта, например
«Оскар Хартманн»].

1. Проведи веб-исследование: проверенные факты биографии, реальные компании,
   его настоящие принципы и дословные цитаты — каждую с источником.
2. Собери папку скилла:
   - SKILL.md — роль, характер, линза из 5–8 вопросов, которыми он проверяет
     мои решения, и формат вердикта;
   - reference/principles.md — фактура и принципы (что подтверждено, что нет);
   - reference/real_quotes.md — только подтверждённые цитаты со ссылками.
3. В SKILL.md пропиши правило заземления: «перед ответом читай reference/;
   не выдумывай цитат и фактов, которых там нет».
4. В description добавь триггеры: при каких моих задачах ты сам зовёшь
   этого наставника.
5. Самотест: задай себе вопрос по моему бизнесу, НЕ называя имя наставника,
   и покажи, что он вызвался и ответил в своём формате.
```

Готовый пример такого скилла — в этой же папке: `oscar-hartmann/`.

## 3. Проверить, что скилл вызывается САМ (самотест триггеров)

```
Проведи самотест моих скиллов. Возьми список моих скиллов, и для каждого:
1. Сформулируй задачу, которая по смыслу подходит скиллу, но НЕ содержит
   его названия.
2. Проверь, вызвался ли скилл сам.
3. Для тех, кто не вызвался — усиль триггерные фразы в description
   (добавь формулировки, которыми я реально говорю) и повтори тест.
Покажи таблицу: скилл → тест-фраза → вызвался/нет → что исправлено.
```

## 4. Придать оркестратору характер

```
Я хочу придать тебе характер. Твоё имя — [имя]. Твой бенчмарк — [например,
«Тим Кук при Стиве Джобсе»]: ты снимаешь с меня операционный шум, споришь
со мной данными, а не поддакиваешь, и проактивно предлагаешь недостающие
скиллы под мои задачи.

Зафиксируй это в CLAUDE.md, чтобы работало в каждом новом чате.

И правило на будущее: каждый раз, когда я говорю «запомни» или даю обратную
связь — превращай её в короткое правило и записывай в память. Так ты обучаешься.
```

---

## Чек-лист здорового скилла

- [ ] Это папка со SKILL.md (не просто текст в чате)
- [ ] В description есть триггерные фразы — скилл вызывается сам
- [ ] У наставника есть reference/ с проверенной фактурой и правило «не выдумывай»
- [ ] У исполнителя есть критерий «работа принята, если …»
- [ ] Самотест пройден: скилл срабатывает без упоминания имени

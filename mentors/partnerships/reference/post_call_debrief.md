## 4. Прогон по 6 ошибкам Данила — признаки

*Какие из типовых ошибок УЖЕ начинают проявляться? Если 3+ — предостеречь.*

- [ ] **1. Подсчёт очков** — кто-то уже считает «я больше сделал»?
- [ ] **2. Разные цели** — видение будущего у партнёров совпадает?
- [ ] **3. Отсутствие фиксации** — согласились устно, не записали?
- [ ] **4. Неравномерное участие** — операционка уже перекошена?
- [ ] **5. Переоценка на ходу** — кто-то хочет поменять правила?
- [ ] **6. Отсутствие механизма выхода** — обсуждали как расходимся?

## 7. 3 развилки решения

*Никогда не даём 1 вариант. Всегда 2-3 с обоснованием.*

2. **Вариант Б:** … (плюсы / минусы)
3. **Вариант В:** … (плюсы / минусы)

## 8. Что зафиксировать в term sheet / корпоративный договор

*По мере того как договорённости становятся зрелыми — добавлять сюда.*

- Долгосрочная цель партнёрства
- Модель + свойства (из `dapopov_framework.md`)
- Распределение ролей
- Распределение долей ИЛИ revenue share
- Финансовая модель
- Механизм разрешения конфликтов
- Механизм выхода (4 сценария — см. `dapopov_framework.md`)
- Эксклюзивность / non-compete / non-solicit
- IP ownership
- Vesting (по Brad Feld — доля разблокируется по milestones)
- Annual review triggers

# Скиллы AI-Потока

Это скиллы для участников [AI-Потока](https://ikigai-community.com) — проверенные инструменты которые мы используем на занятиях.

**Скилл** — это файл с инструкцией для Claude Code. Загружаешь один раз, и Claude начинает работать по нужной методологии автоматически.

---

## Как установить любой скилл

1. Скачай нужный `.md` файл
2. Открой Claude Code → нажми **+** (добавить файл) → выбери скачанный файл
3. Скилл сам настроится — больше ничего не нужно

---

## Встреча 1 — базовый набор (`meeting-1/`)

Устанавливается на первой встрече. Это фундамент системы.

| Файл | Что делает | Как запустить |
|------|-----------|---------------|
| `second-brain-os.md` | Полная операционная система Second Brain: утренний брифинг, GTD, маршрутизация агентов, RAG | Загрузи один раз — работает при каждом запуске |
| `second-brain-architect.md` | Пошаговый мастер первоначальной настройки Second Brain | «настрой мне second brain» |
| `founder-context-extractor.md` | Интервью по 6 блокам — собирает контекст твоего бизнеса в структурированный профиль | «начнём сборку контекста» |
| `morning-brief.md` | Автобрифинг при старте: вчера / цели / фокус / петли / вопрос дня | Срабатывает автоматически при открытии VS Code |
| `gtd-weekly.md` | GTD (Аллен) + Матрица Кови + RPM (Роббинс). 5 режимов: Capture, Priority, RPM, Weekly Review, Shutdown | «разбери мои задачи» |
| `deep-focus.md` | Deep Work (Ньюпорт) + Flow (Чиксентмихайи). 6 триггеров потока, shutdown ritual | «давай поработаем в глубоком фокусе» |
| `triz-solver.md` | ТРИЗ для бизнеса: ИКР, противоречия, 10 изобретательских принципов | «реши это через ТРИЗ» |
| `toc-analyzer.md` | TOC Голдратта: 5 фокусирующих шагов, диаграмма грозовой тучи | «найди бутылочное горлышко» |
| `first-principles.md` | 6 ментальных моделей: первые принципы, инверсия, пре-мортем, Фейнман, Честертон | «разбери задачу с первых принципов» |

## Встреча 2–3 (`meeting-2-3/`)

Даются когда система уже стоит и начинается реальная работа.

| Файл | Что делает | Боль которую решает |
|------|-----------|---------------------|
| `orchestrator-upgrade.md` | Сканирует систему → строит TEAM.md → прописывает маршрутизацию в CLAUDE.md → если нет оркестратора — создаёт базового «Тима». Показывает только финальный зелёный отчёт | Скиллы стоят, но Claude не маршрутизирует сам |
| `deep-build.md` | Методология глубокой разработки: 12 этапов от исследования до деплоя. Режимы S/M/L по размеру задачи | «Много переделываю», «что-то сломалось и непонятно почему» |
| `claude-autoflow.md` | Убирает постоянные клики «да/да/да». Блокирует опасные операции. Звук когда Claude закончил | Замучился подтверждать каждое действие |

## Наставники (`mentors/`)

Скиллы-наставники — это не исполнители, а менторы: смотрят на твоё решение через свою линзу и спорят с тобой. Устанавливаются папкой целиком (SKILL.md + reference/) в `~/.claude/skills/<имя-папки>/`.

| Папка | Кто это | Когда звать |
|-------|---------|-------------|
| `oscar-hartmann/` | Венчурный ментор в стиле Оскара Хартманна. Проверяет решения на unicorn-логику: TAM, unit-экономика, defensibility, виральность | Любое продуктовое решение с амбицией масштаба. «Что скажет Хартманн?» |
| `partnerships/` | Ментор по бизнес-партнёрствам на базе фреймворка Данила Попова (Multiways, Aktivo) + Harvard Negotiation, Chris Voss, Jay Abraham, Brad Feld | Появился потенциальный партнёр, готовишься к созвону, структурируешь сделку, «стоит ли идти в это партнёрство?» |

## Принцип

> Скилл без боли — мёртвый груз. Не торопись устанавливать всё сразу.  
> Ставь скилл когда уже почувствовал проблему которую он решает.

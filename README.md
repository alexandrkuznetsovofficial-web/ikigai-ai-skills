# Скиллы AI-Потока

Это скиллы для участников [AI-Потока](https://ikigai-community.com) — проверенные инструменты которые мы используем на занятиях.

**Скилл** — это инструкция для Claude Code, которая живёт папкой в `~/.claude/skills/`. В шапке инструкции есть `name` и `description` — по описанию Claude понимает, когда скилл звать. Поставил один раз — работает всегда.

В этом репозитории скиллы лежат двумя способами: **папкой** (`SKILL.md` + `reference/` — так устроены наставники, коуч и team-kit) и **одним файлом** `.md` (всё остальное). Ставятся оба одинаково — папкой, см. ниже.

---

## Как установить любой скилл

Открой Claude Code и скажи своими словами:

> «В репозитории `https://github.com/alexandrkuznetsovofficial-web/ikigai-ai-skills` лежит скилл `<путь из таблицы ниже>`. Забери его и установи мне в `~/.claude/skills/` — отдельной папкой по имени скилла, а если это одиночный `.md`, положи его внутрь такой папки под именем `SKILL.md`. Сначала покажи план, потом ставь.»

Claude скачает и разложит сам. Дальше запускаешь скилл фразой из его карточки.

**Два момента, на которых обычно спотыкаются:**

- **Тильда обязательна.** `~/.claude/skills/` — общая папка, скилл виден во всех проектах. Без тильды он останется только в текущей и завтра в другой папке не запустится.
- **Не «плюсиком».** Файл, приложенный к чату через **+**, живёт до конца сессии: закроешь редактор, вернёшься завтра, скажешь фразу — ничего не произойдёт.

## Наставники (`mentors/`)

Скиллы-наставники — это не исполнители, а менторы: смотрят на твоё решение через свою линзу и спорят с тобой. Устанавливаются папкой целиком (SKILL.md + reference/) в `~/.claude/skills/<имя-папки>/`.

| Папка | Кто это | Когда звать |
|-------|---------|-------------|
| `oscar-hartmann/` | Венчурный ментор в стиле Оскара Хартманна. Проверяет решения на unicorn-логику: TAM, unit-экономика, defensibility, виральность | Любое продуктовое решение с амбицией масштаба. «Что скажет Хартманн?» |
| `partnerships/` | Ментор по бизнес-партнёрствам на базе фреймворка Данила Попова (Multiways, Aktivo) + Harvard Negotiation, Chris Voss, Jay Abraham, Brad Feld | Появился потенциальный партнёр, готовишься к созвону, структурируешь сделку, «стоит ли идти в это партнёрство?» |

## Коуч (`coach/`)

Второй мозг знает твой бизнес, но не знает тебя. Коуч закрывает эту половину: он живёт рядом, разговаривает с тобой о деле и жизни — и попутно вытаскивает контекст о тебе самом, складывая его в память. Не анкетой, а по вопросу за разговор.

| Папка | Кто это | Когда звать |
|-------|---------|-------------|
| `ikigai-provodnik/` | Лайф-коуч второго мозга. Помнит твой контекст и смотрит на любой вопрос через твой переход, твои сильные стороны и твои сценарии. Сам видит, чего в памяти не хватает, и добирает. Ведёт карту: стадия перехода · сильные стороны · где модель разошлась с тобой · идеальный день · архетип и три сценария | «Поговорим», «давай подумаем вслух», «я застрял», «разрываюсь», «распакуй меня», «что ты обо мне знаешь», «чего не хватает в моей памяти» |

Ставится папкой целиком (`SKILL.md` + `reference/`) в `~/.claude/skills/ikigai-provodnik/`.

Что делает с добытым: выжимает суть, спрашивает «что здесь неточно?», кладёт файлы в `memory/` и обновляет `CLAUDE.md` — иначе твои агенты про тебя так и не узнают. При расфокусе («всё горит», «куча задач») переключается в фокус-сессию и выводит одну ведущую задачу вместо списка.

Стоит на модели переходов Бриджеса, Working Identity Ибарры, VIA/Gallup и Self-Determination Theory; раскладка памяти — по CODE и PARA Тиаго Форте.

## Встреча 4 — «Новоселье»: твоя IT-команда (`team-kit/`)

Подарок урока о переезде на сервер. Пять специалистов, которые обслуживают твой сервер, безопасность и качество решений. Устанавливаются папками целиком: `team-kit/skills/<имя>/` → `~/.claude/skills/<имя>/`.

| Скилл | Кто это | Когда звать |
|-------|---------|-------------|
| `cto/` | Точка входа для любой технической задачи. Разберёт и позовёт нужного из команды | «Сломалось», «задеплой», «как правильно», «безопасно ли» |
| `devops/` | Сервер 24/7: сбои, логи, перезапуск, бэкапы, диск, память, сеть | Что-то с сервером или сервисом |
| `secops/` | Секреты и доступы: токены в сейфе, вход по ключу, изоляция, аудит | Всё про ключи, пароли и защиту |
| `code-reviewer/` | Проверяет любую правку **до** запуска. Вердикт 🟢/🟡/🔴 | Перед каждым деплоем |
| `anthropic-academy/` | Отвечает «как правильно» по первоисточникам Anthropic, а не догадками | «А как эту штуку делать по канону?» |

Главное правило: не зови всех подряд — иди к `cto`, он диспетчер. Текст для установки — в [`team-kit/README.md`](team-kit/README.md).

## 🎓 Конструктор LMS — своя платформа обучения (`lms-constructor-kit/`)

Полный путь от «хочу обучать сотрудников на своей платформе, но не знаю, с чего начать» до работающего MVP: **бриф на 100 вопросов → ТЗ → согласование с агентом-ревизором → кликабельный прототип → MVP → пилот на живых людях**. Собран на опыте производства реальной академии и мировых платформ (GetCourse, Teachable, TalentLMS, iSpring и др.).

Внутри четыре модуля с готовыми промптами и пачка из трёх скиллов: `lms-constructor` (архитектор, ведёт по этапам), `lms-prototyper` (кликабельный прототип), `lms-builder` (сборка до MVP). Начни с [README кита](lms-constructor-kit/README.md).

## 🌐 Website-kit — сайт под ключ (`website-kit/`)

От «хочу сайт» до опубликованной страницы за одну сессию: координатор `website-builder.md` ведёт по 8 шагам — распаковка смыслов (5 вопросов + выгрузка твоего TG-канала) → референсы (`content-researcher.md`) → архитектура продающего лендинга (`landing-architect.md`, синтез StoryBrand + Schwartz + Hormozi + Levels + Apple Lens) → вёрстка (встроенный frontend-design) → дизайн-критика (`design-critique.md`) → SEO (`seo.md`) → юридический минимум 152-ФЗ → деплой (свой сервер или Netlify). Начни с [README кита](website-kit/README.md).

## ✍️ Копирайтинг-пак — личная AI-редакция (`copywriting-pack/`)

| Файл | Что делает | Как запустить |
|------|-----------|---------------|
| `tone-of-voice-builder.md` | Собирает твой голос из выгрузки TG-канала или 3–5 постов → `voice.md` | «собери мой голос» — **ставится первым** |
| `copywriter-multiplatform.md` | Из голосовухи/тезисов — пакет постов под 4 платформы сразу | «напиши пост», «вот мои мысли» |
| `instagram-copywriter.md` | Хук 125 симв., карусели, Reels, сторис + compliance РФ | «пост для инсты», «сделай карусель» |
| `linkedin-copywriter.md` | Хук 210 симв., anti-AI тон, ссылки в комментарий | «пост для LinkedIn» |
| `threads-copywriter.md` | До 500 симв., цепочки, replies > likes | «напиши для Threads» |
| `anti-slop-filter.md` | Финальная зачистка ИИ-маркеров из любого текста | «зачисти от ИИ», «анти-слоп» |

Начни с [README пака](copywriting-pack/README.md).

## 🎯 Фокус-пак — «Одна вещь» (`focus-pack/`)

Линза по книге Гэри Келлера «The ONE Thing»: каждый день отвечает на вопрос «что ЕДИНСТВЕННОЕ делать сегодня, чтобы всё остальное стало проще или ненужным?». При первом запуске строит твою лестницу целей (когда-нибудь → год → месяц → неделя → сегодня), дальше из реального списка дел выбирает ОДНУ ведущую домино — с названными жертвами дня, тайм-блоком и защитой от 4 воров фокуса. Умеет вылезать сама при перегрузе и новых идеях поверх незаконченных (готовый блок для твоего CLAUDE.md — внутри). Начни с [README пака](focus-pack/README.md).
